## 1. 這一關在回答什麼問題

老師的要求：

> 「第一個通常會先判斷**有沒有線性**…有線性的才拿出來，**沒有線性表示這個因子不行**」

翻成白話：**把一個因子從最低濃度排到最高濃度，報酬會不會穩定地往上（或往下）走？**

- 會 → 這是**真訊號**
- 忽高忽低 → 這是**雜訊**，再怎麼跟別的因子搭配也只是把雜訊帶進去

## 2. 實驗設計：一次只開一個構面

一個「策略」＝ `F1 × F2 × C × V` 四個構面的組合，策略數是**連乘**出來的。
Phase 1 刻意把其他三個構面全部關掉：

| | 平常一批 | **Phase 1** |
|---|---|---|
| F1 | 20 個條件 | **9 個（一個因子切 9 桶）** |
| F2 | 配對 170 種 | ❌ 關（固定不配第二個） |
| C | 21 種 | ❌ 關（固定不加動態條件） |
| V | 2 種 | ❌ 關（固定 v0 不套估值濾網） |
| **策略數** | 170×21×2 = **7,140** | 9×1×1 = **9 / 因子** |

20 個因子 → **180 個策略**，執行時間 8.5 分鐘。

**便宜不是偷工減料**，而是因為它問的是一個更單純的問題：
要判斷「這個因子自己有沒有訊號」，就不能讓其他構面幫忙。

> 附帶驗證：先跑過含 V 的版本（360 策略），關掉 V 後**所有線性檢定數字完全相同**
> ——確認先前的分析本來就只用 v0，關 V 純粹省掉一半白跑的運算。

## 3. 判定規則

| 條件 | 判定 |
|---|---|
| \|ρ\| ≥ 0.85 且 p < 0.05 | ✅ 過關 |
| \|ρ\| < 0.5 但頭尾某一桶顯著優於其餘 | ⚠️ 只取極端桶 |
| 0.5 ≤ \|ρ\| < 0.85 | ⚠️ 邊際 |
| \|ρ\| < 0.5 | ❌ 淘汰 |

ρ＝Spearman 等級相關（桶序 vs CAGR），±1 為完美單調、0 為毫無方向性。

## 5. 六個主要發現

### 發現一：過關的只有兩種訊號，而且方向相反

```
估值類 PB / PS / P_IC / EV_S    ρ 全為負 → 越便宜越好
動量類 MOM                       ρ 為正   → 動能越強越好
```

一個是「買便宜」、一個是「跟趨勢」，**是經典的兩種獲利來源，而且互不重疊**。
對 Phase 2 是好消息：它們搭配起來理論上有加成效果，不是重複同一個訊號。

### 發現二：四個估值因子的最高點都在「桶1」不是「桶0」⭐

```
PB    桶0 13.17% → 桶1 16.47%(最高) → 桶8  4.87%
P_IC  桶0 11.59% → 桶1 17.06%(最高) → 桶8  3.27%
PS    桶0 12.58% → 桶1 15.51%(最高) → 桶8  6.86%
EV_S  桶0 12.62% → 桶1 15.01%(最高) → 桶8  7.97%
```

**四個因子一致呈現「最便宜的那一桶反而不是最好的」**——教科書級的「價值陷阱」證據：
絕對最便宜的股票，便宜是有原因的（公司真的有問題）。

**而這只有切到 9 桶才看得見。** 先前切 5 桶時，桶0 與桶1 被合併成同一桶、被平均掉了。

> 📌 **這是可以直接向指導教授證明「細切確實看出新東西」的具體成果。**

### 發現三：舊實驗的三個「固定因子」沒有一個過關 ⭐

```
ROE    ρ = +0.833  ⚠️ 邊際
EPS    ρ = +0.650  ⚠️ 邊際
FCF_P  ρ = +0.133  ❌ 淘汰
```

先前 10 批實驗的整個前提——「ROE/EPS/FCF_P 固定當基底、只換候選因子」——
**從未通過驗證，而且現在證實它站不住腳**。老師的質疑（「ROE 的區隔有點怪」）命中。

**FCF_P 被淘汰還反過來解釋了我們自己的舊發現。** 它的 9 桶曲線完全鋸齒：

```
11.20% → 6.61% → 9.22% → 8.08% → 5.70% → 9.82% → 10.29% → 9.77% → 9.73%
```

沒有任何方向性。而先前分析 C 構面時發現「C15~C20（FCF_P 衍生的動態條件）
在 10 批裡一致墊底」——**原因就是因子本身沒訊號，拿它衍生的動態條件當然也沒用**。
兩個獨立分析互相印證。

### 發現四：新增的 4 個因子有 3 個被淘汰

```
NETDEBT_EBITDA  ρ = +0.550  ⚠️ 邊際
ACCRUAL         ρ = −0.367  ❌ 淘汰
REV_G           ρ = +0.250  ❌ 淘汰
VOL             ρ = −0.250  ❌ 淘汰
```

這 4 個是 2026-08-06 為了補齊「應計品質／成長／波動」三個空白類別而新增的。
結果 3 個沒過。

**建議照實報告、不要為它們找藉口。**
這反而是這套 SOP 的說服力來源：**我們自己挑進來的因子，沒有因為「是我們挑的」就過關。**

（附帶觀察：VOL 從桶0 到桶7 一路下滑 9.10%→5.75%，符合低波動異象的方向，
但桶8 突然跳回 10.38%，形成 U 型。台股極高波動族群裡可能有一批飆股。
ρ 僅 −0.25，不足以過關。）

### 發現五：MOM1 是最好的「反面教材」🚫

```
MOM1  桶0 −22.06% → 桶8 +67.77%    跨度 90 個百分點，ρ = 1.000
MOM   桶0  +2.86% → 桶7 +11.89%    跨度  9 個百分點，ρ = 0.933
```

MOM1 的數字**好到不合理**：是 20 個因子裡唯一 ρ=1.000 的，跨度是其他因子的 7 倍，
而且是**唯一有負值桶的因子**（其他 19 個因子的 9 個桶幾乎全部贏大盤）。

**根因**：MOM1 =（公告日**+45天**收盤 − 期末日收盤）/ 期末日收盤，
但 `format_data.py::adjust_index_of_report` 讓財報在**公告日當天**就可用：

| 季別 | 公告日（可用） | MOM1 需要的價格日 | 偷看天數 |
|---|---|---|---|
| Q1 | 5/15 | 6/29 | 45 天 |
| Q2 | 8/31 | 9/28 | 28 天 |
| Q3 | 11/15 | 12/29 | 44 天 |
| Q4 | 3/31 | 5/15 | 45 天 |

**等於在 5/15 挑股票時，挑股票的依據裡已經包含 6/29 的股價。**
挑出來的當然都是接下來會漲的——這不是預測能力，是偷看答案。

**MOM 本身乾淨**：公告日當天兩個價格都已知，無偷看。且 lab 的可用日（8/31、11/15）
還比 collector 的公告日（8/14、11/14）更晚，更保守。

**處置**：`phase1_linearity.LOOKAHEAD_FLAGGED = {"MOM1"}`，
照跑照畫圖但判定覆寫為 `🚫 前瞻偏誤`、不列入評選。
**刻意不刪除**——把它跟乾淨的 MOM 並排，是很有說服力的報告素材。
要真正救回需回 collector 改成「往前推」的定義。
⚠️ **美股 MOM1 定義相同，跑美股 Phase 1 前要先處理。**

### 發現六：幾乎所有因子的所有桶都贏大盤 ⚠️

大盤基準只有 **4.71%**，而 20 個因子中有 **16 個是 9 個桶全部贏大盤**。

這代表**「有財報資料、能被選進來」這件事本身就已經贏大盤**，
是一個**基準效應**而非因子的功勞。**必須在論文裡誠實交代**，
不能把它算成任何一個因子的貢獻。

## 6. ⚠️ 大盤基準已改變：6.24% → 4.71%

| | 期間 | 年化 |
|---|---|---|
| 舊報告用的 | 2000-01-04 ~ 2026-07-24 | **6.24%** |
| **本次（in-sample）** | 2000-01-04 ~ **2025-12-31** | **4.71%** |

差異來自**拿掉 2026 年**——2026 年台股漲勢很強，短短 7 個月就把 26 年的年化拉高 1.5 個百分點。

**所有舊報告的「贏大盤比例」都是用 6.24% 算的，不可與本次結果直接比較。**

## 7. 對 Phase 2 的建議

過關 5 個、邊際 5 個，剛好對應老師的**不對稱設計**：

> 「你一個把它定成 **primary**，一個是 **secondary**…primary 一定要是有意義的，
> secondary 就是要符合某些[寬鬆條件]…至少跟大盤差不多，或者說是輸大盤不多」

| 角色 | 候選 | 門檻 |
|---|---|---|
| **F1 (primary)** | PB、PS、P_IC、MOM、EV_S | 嚴格：Phase 1 過關 |
| **F2 (secondary)** | ROE、ROIC、OCF_E、EPS、NETDEBT_EBITDA | 寬鬆：不拖累即可 |
| 待決 | REVENUE、DEBTRATIO | 「只取極端桶」，需個別決定取哪一桶 |
| **完全排除** | 淘汰的 7 個 + MOM1 | 不進 Phase 2 |

### 建議在 CP1 與老師確認的三件事

1. **邊際的 5 個是否放行當 secondary**（若不放行，F1×F2 配對數會太少）
2. **REVENUE / DEBTRATIO 的「只取極端桶」怎麼處理**——REVENUE 最佳在桶0（小型股效應）、
   DEBTRATIO 最佳在桶8，兩者都是 U 型
3. **ROE/EPS/FCF_P 沒過關**這件事的後續處理——這推翻了先前 10 批實驗的前提
