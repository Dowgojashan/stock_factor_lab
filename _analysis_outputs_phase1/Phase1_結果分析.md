## 1. 這一關在回答什麼

指導教授 2026-08-05 meeting 的核心指示：

> 「第一個通常會先判斷**有沒有線性**…有線性的才拿出來，**沒有線性表示這個因子不行**」
> 「我大概會先把它切割成 8、9 個區間吧，然後再湊回來。因為 3 的倍數嘛」

意義在於**先驗地**決定因子去留，而不是等看到績效再回頭挑桶——後者就是老師說的「作弊」。

## 2. 實驗設計：一次只開一個構面

| 構面 | Phase 1 | 說明 |
|---|---|---|
| F1 | ✅ 開（9 桶） | 每個因子單獨切 9 個橫斷面分位 |
| F2 | ❌ 關 | 同因子的桶不互相配對（引擎既有邏輯） |
| C | ❌ 關 | P3 留空 → 只有 C=None |
| V | ❌ 關 | `V_MODES=("v0",)` |

每因子產生 9 個策略，20 個因子共 180 個。

## 3. 判定規則

```
|ρ| ≥ 0.85 且 p < 0.05          → ✅ 過關
0.5 ≤ |ρ| < 0.85                 → ⚠️ 邊際（看形狀）
|ρ| < 0.5                        → ❌ 淘汰
  例外：頭或尾單獨明顯高過其餘（>3pp）且贏基準 → ⚠️ 只取極端桶
```
ρ = Spearman 等級相關（桶號 vs 該桶 CAGR）。

## 6. 五個主要發現

### 發現一：兩個市場都由「估值」主導，但強度不同 ⭐

`P_IC` / `PB` / `PS` / `EV_S` **四個估值因子在台美都過關**，而且都是**最便宜桶最好**。
這是本研究最穩固的結論——跨市場、跨資料版本都成立。

差別在強度：美股最便宜桶 30.78%~39.18%，台股 16.79%~22.20%。

### 發現二：`MOM` 的方向在兩個市場相反 ⭐⭐

```
台股  ρ = +0.933  單調↑   最佳桶 qb7（動能強）   → 動量效應
美股  ρ = −0.050  U 型    最佳桶 qb0（動能最弱） → 反轉效應
```

**同一個因子、同一套定義，在兩個市場的方向完全相反。**
這直接支持「因子不能跨市場直接沿用」，是論文很有力的一段。

### 發現三：美股大量 U 型，台股多為單調 ⭐

美股 20 個因子有 **9 個是「只取極端桶」（U 型：兩端好、中間差）**，台股只有 1 個。

U 型的意義是「極端值有訊號、中庸沒有」。美股的公司分散度遠大於台股
（2,972 檔 vs 1,775 檔，且市值跨度更大），中段公司彼此差異小、訊號被稀釋。

### 發現四：`ROE` 在台股過關、在美股只取極端桶

```
台股  ROE ρ = +0.867 單調↑  ✅ 過關
美股  ROE ρ = −0.017 U 型   ⚠️ 只取極端桶
```
台股的獲利能力有單調的預測力，美股沒有——美股的 ROE 已被市場充分定價，
只有極端值（極高或極低）還帶訊號。

### 發現五：`MOM1` 是最好的反面教材 🚫

```
台股  ρ = +1.000（完美）  最佳桶 CAGR 67.79%
美股  ρ = +1.000（完美）  最佳桶 CAGR 70.88%
```

`MOM1 = (公告日+45天收盤 − 期末日收盤)/期末日收盤`，但 `format_data.py` 讓財報在
**公告日當天**就可用 → 選股時已經知道未來 45 天的股價。

**兩個市場都給出完美的 ρ=1.000 和近 70% 的年化**——這正是前瞻偏誤的典型特徵：
好得不像真的。它照跑、照畫圖，但**判定一律覆寫為 🚫、不列入評選**，
在論文裡當成「為什麼要嚴格檢查資料時序」的實例。

## 7. 📌 資料品質：這份報告為什麼被全面改寫

> 這一節記錄的過程本身就是論文的素材，建議完整保留。

### 7.1 先前版本發現了什麼

2026-08-06 的第一版 Phase 1 跑在當時的資料上，出現一個當時無法解釋的異常：

> **「20 個因子中有 16 個是 9 個桶全部贏大盤」** ——當時只能寫成
> 「這是**基準效應**而非因子的功勞，必須在論文裡誠實交代」。

同時 `PB` 的曲線不單調（最高點在桶1 而非桶0），`ROE`/`ROIC` 只到「邊際」，
`EV_EBITDA`/`ACCRUAL`/`FCF_OI`/`FCF_P` 全被淘汰。

### 7.2 追查結果：是資料，不是方法

2026-08-12 查證發現台股 2000-2004 的財報**幾乎不存在**：

- 上游 `financialreportindicatorvalue` 的**全部 17 個財報科目在 2000-2004 都是 0 家公司**，
  只有「收盤價」與「本益比」有值
- `factorvalue` 裡雖有值，但**其中 55~90% 是剛好 `0.00`**（PB/PS/P_IC/FCF_P 達 90%）
- 有值的公司數 690→603→513→431→355（**逐年遞減**，與上市公司數的自然成長相反）

**機制**：`q_band` 用 `rank(pct=True)`，並列值取**平均排名**。
90% 的假 `0.00` 全部擠在百分位中段 → **最低的幾個分位桶完全撈不到股票**。
實測 `PB_qb0` 要到 2005 才有持股，而 `PB_qb8` 從 2002 就有。

→ 各桶「實際開始持股的年份」不同，9 桶 CAGR 不可比，ρ 也失真。
→ 而低桶空手的年份不會虧錢，**這就是「什麼都贏大盤」的來源**。

### 7.4 🔴 「什麼都贏大盤」的異常已消失

```
贏大盤桶數（9 桶中）  修復前：20 個因子有 16 個是「9 桶全贏」
                      修復後：P_IC 5 ｜ PB 5 ｜ PS 5 ｜ EV_S 6 ｜ MOM 4 ｜ VOL 3
```

**原本要在論文裡道歉的一個弱點，證實是資料問題而非方法問題。**
現在多數因子只有一半的桶贏基準——這才是合理的樣態。

### 7.5 留下的限制

- **2023-2025 有約 37 家公司有股價但無因子資料**。使用者 2026-08-14 確認
  **TEJ 沒有這批資料**，不再回補。影響：2.1% 的宇宙、26 年裡的 3 年。
- **2000-2004 的可交易宇宙較小**（573~951 檔，2005 後為 1,139+）。
  但這是**真實的市場規模**（`stock` 表 2000 年只有 581 家上市公司），
  不是資料缺失——估值因子的覆蓋率是價格宇宙的 98.6%。
- 中間過程的封存與診斷紀錄：`code/_ARCHIVE_TW_predata_backfill/README.md`
