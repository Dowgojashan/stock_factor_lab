## 1. 這一關在回答什麼問題

> 「**我有 20 個因子，我要怎麼找出一個好的 F1×F2 的組合**，這個 SOP、這個方法論，你這個要有」

也就是：**加上第二個因子，到底有沒有幫助？哪些組合值得留到下一關？**

## 2. 設計

**因子池 12 個**（Phase 1 淘汰的 7 個與前瞻偏誤的 MOM1 完全不進來）：

| 角色 | 因子 | Phase 1 判定 |
|---|---|---|
| **primary（5）** | PB, PS, P_IC, MOM, EV_S | ✅ 過關 |
| **secondary（7）** | ROE, ROIC, OCF_E, EPS, NETDEBT_EBITDA | ⚠️ 邊際 |
| | REVENUE, DEBTRATIO | ⚠️ 只取極端桶 |

**規模**：12 因子 × 3 桶 = 36 條件 → 單因子 36 + 跨因子配對 594 = **630 策略**（28.9 分鐘）

**9 桶 → 3 桶**：直接用 `q_band(k,3)`，數學上等同把 9 桶的 {0,1,2}/{3,4,5}/{6,7,8} 合併，
但**是實跑不是算數合併**（與老師的技術分歧，見 `重跑計畫_老師方法論SOP.md` §3.2）。

**角色不對稱的實作**：`F1∩F2` 與 `F2∩F1` 遮罩相同、回測結果相同——
**不對稱的是「評選標準」不是「策略本身」**。所以 12 個因子全放進同一個 P1 讓引擎配對
（不改引擎、不重複回測），角色與門檻在**分析層**才套用。

## 3. 門檻（對應老師原話，可調）

| 參數 | 值 | 對應老師的話 |
|---|---|---|
| `PRIMARY_MARGIN` | 贏大盤 ≥ 2pp | 「primary 一定要是…有意義的」 |
| `SECONDARY_TOL` | 輸大盤 ≤ 1pp | 「至少跟大盤差不多，或者說是輸大盤不多」 |
| `COMBO_DEGRADE_TOL` | 退步 ≤ 0.5pp | 「primary 加上某一點點比較寬鬆的 secondary **夠強了**」 |
| `MIN_HOLDINGS` | ≥ 10 檔 | 「裡面被選出來的[股票]不能太少，那就是策略不[穩定]」 |

## 5. 五個主要發現

### 發現一：加 F2 平均而言「沒有幫助」⭐

```
配對增益中位數     = −0.04%
增益為正的比例     = 49.0%
```

**幾乎完全對半、中位數貼著零。** 也就是說，隨便加一個第二因子，
有一半機會變好、一半機會變差，**期望值是零**。

這直接印證老師的設計：**F2 必須是「挑過的」，不能亂加**，而且
「**F2 可以是空集合**」不是客套話——primary 自己夠強時，不加 F2 是完全合理的選擇。

### 發現二：Phase 1「過關」的因子，當 secondary 反而是拖累 ⭐⭐

各 secondary 因子的配對增益中位數：

| secondary | 增益中位數 | Phase 1 判定 |
|---|---|---|
| **NETDEBT_EBITDA** | **+1.78%** | ⚠️ 邊際 |
| **DEBTRATIO** | **+1.59%** | ⚠️ 只取極端桶 |
| **REVENUE** | **+1.57%** | ⚠️ 只取極端桶 |
| PS | −0.02% | ✅ 過關 |
| EV_S | −0.35% | ✅ 過關 |
| OCF_E | −0.58% | ⚠️ 邊際 |
| EPS | −1.14% | ⚠️ 邊際 |
| ROE | −1.22% | ⚠️ 邊際 |
| ROIC | −1.30% | ⚠️ 邊際 |
| P_IC | −1.46% | ✅ 過關 |
| PB | −1.71% | ✅ 過關 |
| **MOM** | **−2.72%** | ✅ 過關 |

**唯三中位數為正的（NETDEBT_EBITDA / DEBTRATIO / REVENUE），在 Phase 1 全部只是
「邊際」或「只取極端桶」；而墊底的 MOM / PB / P_IC 在 Phase 1 全部「過關」。**

**為什麼會反過來？**

因為 PB / PS / P_IC / EV_S 都是**估值倍數**，彼此高度相關——疊加起來只是
**把同一個訊號講兩遍**，卻把持股數砍半，分散度下降、訊號沒增加，淨效果是負的。
MOM 更極端：它與估值因子的方向相反（動能強的股票通常不便宜），硬疊會互相抵銷。

而 NETDEBT_EBITDA（財務結構）、REVENUE（規模）、DEBTRATIO（負債）提供的是
**完全不同構面**的資訊，才有真正的加成。

> 📌 **這是 Phase 2 最有價值的發現，而且正好解釋了老師 primary/secondary 不對稱設計的深層道理：
> secondary 不需要「自己強」，它需要的是「提供不同的資訊」。**
> 這也是一個能寫進論文的方法論貢獻——**單因子強度與配對價值是兩件事**。

### 發現三：3 桶太粗，選出來的股票太多 ⚠️

```
單因子（3 桶）平均持股數 ≈ 434 ~ 514 檔
配對後            平均持股數 ≈  90 ~ 180 檔
晉升組合的中位數                    162 檔
```

台股有財報資料的公司約 1,775 家，**1/3 就是約 590 家**——
單因子 3 桶等於持有全市場的 29%，**這已經接近指數基金了**。

老師說「切 3 個區間，因為這樣子樣本才夠大」，本意是讓**統計樣本**夠大；
但副作用是**投組持股數也跟著變大**。

因此 `MIN_HOLDINGS = 10` 這道防線在本階段**幾乎沒有作用**（630 個裡只擋掉 3 個）。
它要到 Phase 3 加入 C 條件、把選股範圍收窄之後才會真正發揮作用。

### 發現四：冠軍組合非常突出，但要小心 ⚠️

```
P_IC_qb0 × PB_qb2
CAGR 26.31%（第二名 22.43%）｜配對增益 +11.90%｜MDD −50.4%｜平均持股 18 檔
```

**這個組合的經濟意義很有意思**：
- `P_IC_qb0` = 市值/總資產**最低** → 相對總資產便宜
- `PB_qb2` = 市值/股東權益**最高** → 相對股東權益貴

兩者相除可推得 **總資產/股東權益很高 → 這是在選「高財務槓桿」的公司**。
用高槓桿放大便宜資產的報酬——邏輯上說得通。

**但有三個警訊必須一起講**：
1. 平均只持 **18 檔**，是所有晉升組合裡最少的（中位數 162 檔），**個股集中度風險高**
2. 增益 +11.9% 是第二名（+8.0%）的 1.5 倍，**在 630 個組合裡屬於極端離群值**
3. 勝率僅 48.9%，MDD −50.4%

**建議**：留到 Phase 3，但**單獨標記追蹤**，並在 Phase 3 結束後做一次
類似先前 `champion_concentration_check` 的集中度檢查，確認不是靠少數個股撐起來的。

### 發現五：五個 primary 因子的晉升數相當平均

```
EV_S 48 ｜ PS 43 ｜ P_IC 38 ｜ PB 38 ｜ MOM 36
```

沒有哪個 primary 明顯壓倒其他，**代表 Phase 1 選出的 5 個因子品質相當**，
不是靠某一個因子撐場面。這對 Phase 3 是好消息：F 構面的基礎是穩的。

可以做風險控管——這正是 Phase 3/4 要處理的事。**現階段不需要為此調整因子選擇。**

## 7. 對 Phase 3 的建議

### 帶進 Phase 3 的
**203 個晉升組合**（`TW_L2_體質檢查表.csv`），即老師說的「**固定的體質檢查表**」。

### 建議在 Phase 3 開始前確認的三件事

1. **secondary 池是否收斂？**
   既然只有 NETDEBT_EBITDA / DEBTRATIO / REVENUE 三個有正增益，
   是否把 secondary 限縮成這三個？這會讓 Phase 3 的規模大幅下降、也更有理論依據
   （「secondary 要提供不同構面的資訊」）。
   ⚠️ 但這等於用 in-sample 結果再篩一次，**有過度配適的疑慮**，需要跟老師討論。

2. **203 個是否太多？**
   老師說「剩下的不可以太少，不然後面就沒有 LLM 的必要」，但也沒說要多少。
   203 個組合 × 21 個 C 狀態 = 4,263 個策略，規模合理。

3. **冠軍組合 P_IC_qb0 × PB_qb2 的特殊處理**（見發現四）。
