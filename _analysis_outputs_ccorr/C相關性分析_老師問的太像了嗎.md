# 20 個 C 是不是太像了？（台股 + 美股）

> **執行日期**：2026-08-17（A1 修正後重算）
> **問題來源**：2026-08-05 指導教授 meeting，老師直接問「這些 C **是不是太像了**」
> **變體**：openSec｜**資料**：台股 4,599 策略／219 F 組合；美股 3,948 策略／188 F 組合
> **執行腳本**：`code/c_correlation.py`（**不需重跑回測**）
> **原始資料**：`{TW,US}_openSec_C_corr.csv` / `_C_jaccard.csv` / `_C_similarity.png`
>
> 🔴 **本文為 2026-08-17 全面改寫版。** 先前版本的**美股數字全部無效**——
> 當時美股的 `qmax` 家族恆真、`riseq`/`yoy` 恆假（A1 缺陷），
> 「qmax 跨因子塌縮 Jaccard 0.993」是 bug 的必然結果，不是市場特性。
> 詳見 `_analysis_outputs_phase3/Phase3_結果分析.md` §5。

## 1. 怎麼量「像不像」

| 指標 | 量什麼 | 為什麼需要 |
|---|---|---|
| **選股重疊**（Jaccard） | 兩個 C 實際選到的股票有多少是同一批 | 最直接的「像」，與報酬無關 |
| **績效相關**（Spearman） | 兩個 C 套在同一批 F 組合上，增益是否同向 | 回答「換一個 C 有沒有實質差別」 |

Jaccard＝交集/聯集，對持股數差很多的配對比較公允。

---

## 2. 答案：**沒有太像**

```
              中位     p90     最高
台股 績效相關  0.329   0.679   0.915
台股 選股重疊  0.306   0.510   0.844
美股 績效相關  0.209   0.667   0.933
美股 選股重疊  0.285   0.497   0.815
```

**中位數都在 0.33 以下。** 若 20 個 C 真的是同一個東西，這些數字應該逼近 1。

最高的幾對到 0.8~0.93，代表有具體的重複——但那是**可以指名道姓的少數幾對**，
不是普遍現象。

> 📌 修正 A1 前，美股的選股重疊最高是 **0.993**（`EPS_qmax4` ↔ `ROE_qmax4`），
> 當時被寫成「qmax 家族跨因子塌縮」並提出「美股 ROE/EPS/FCF 高度同步」的機制假說。
> **那整段是 bug 的產物**——三個 qmax 都恆真，當然選到同一批（＝F 組合原本那批）。
> 修正後美股的最高重疊降到 **0.815**，而且是同因子的相鄰規則，不是跨因子。

---

## 3. 重複來自哪裡：兩個市場都由「因子」主導

把配對拆成三類：

### 績效相關（中位數）

| 配對類型 | 對數 | 台股 | 美股 |
|---|---|---|---|
| **同因子 · 不同規則** | 57 | **0.406** | **0.506** |
| 同規則 · 不同因子 | 19 | 0.430 | 0.206 |
| 都不同 | 114 | 0.266 | 0.091 |

### 選股重疊（中位數）

| 配對類型 | 對數 | 台股 | 美股 |
|---|---|---|---|
| **同因子 · 不同規則** | 57 | **0.420** | **0.345** |
| 同規則 · 不同因子 | 19 | 0.318 | 0.328 |
| 都不同 | 114 | 0.291 | 0.249 |

**兩個市場、兩個指標，三組裡有三組是「同因子」最高。**
（台股的績效相關是唯一例外，同規則 0.430 略高於同因子 0.406，差距 0.024 在雜訊範圍內。）

> ⚠️ **這裡推翻了先前兩次的說法。**
> - 2026-08-10（假 0 資料）：「台股由因子主導、美股由規則主導，兩者完全相反」
> - 2026-08-15（A1 修正前）：「美股單一維度（規則）主導，台股勢均力敵」
>
> 修正後的正確說法是：**兩個市場都由「用哪個來源因子」主導，美股尤其明顯
> （同因子 0.506 vs 同規則 0.206，差 2.5 倍）。**
>
> 這也與 Phase 3 的發現一致——兩市場的 C 都是**依來源因子**分好壞
> （台股 ROE/EPS 全正、FCF_P 全負；美股 EPS 全正、FCF_P 偏負）。

## 4. 具體哪幾對該注意

### 兩個市場共通的兩對

```
台股  C13_EPS_ytdavg_gt_lyytdavg ↔ C14_EPS_ytdavg_gt_lyavg   Jaccard 0.844
      C6_ROE_ytdavg_gt_lyytdavg  ↔ C7_ROE_ytdavg_gt_lyavg            0.829
美股  C13 ↔ C14                                                      0.815
      C6  ↔ C7                                                       0.791
```

**`ytdavg_gt_lyavg` 與 `ytdavg_gt_lyytdavg` 這兩條規則實質上很接近**——
差別只在比較基準是「去年全年平均」還是「去年同期平均」。
兩個市場、兩個來源因子都出現 0.79~0.84 的高重疊，這是**穩健的重複**。

### 台股額外的一組

```
C2_ROE_riseq2 ↔ C9_EPS_riseq2   0.799
C1_ROE_riseq1 ↔ C8_EPS_riseq1   0.784
```
台股的 `ROE` 與 `EPS` 在「連續成長」這類規則上高度重疊（兩者都是獲利面因子）。
美股沒有這個現象（同規則不同因子只有 0.328）。

## 5. 怎麼回答老師

> **「不會太像。20 個 C 的中位相關只有 0.33（台股）與 0.21（美股），
> 選股重疊也只有 0.31 與 0.29。真正重複的是可以指名的兩對——
> `ytdavg_gt_lyavg` 與 `ytdavg_gt_lyytdavg`（重疊 0.79~0.84），
> 它們的差別只在比較基準是去年全年還是去年同期。
> 而相似度主要由**用哪個來源因子**決定，不是用哪條規則。」**

### 三層反證：C 確實不是同一個東西

1. **排名幾乎不相關**：兩市場 20 個 C 的增益排名 Spearman 僅 **0.149**
2. **同一個 C 在兩市場一個第一、一個最後**：`C4_ROE_qmax8` 台股 +6.86%（第 1）、
   美股 −2.33%（第 20）
3. **最佳家族不同**：台股靠 `qmax`（創新高），美股靠 `yoy`（年增）

### 若老師要求精簡

保守的刪減建議（20 → 17）：每個來源因子的 `ytdavg` 兩個變體擇一保留，
刪掉 `C6` / `C13` / `C20`（`ytdavg_gt_lyytdavg` 那一支）。

⚠️ **但要注意**：美股的 `C13_EPS_ytdavg_gt_lyytdavg` 排名第 2（+2.38%），
比保留的 `C14`（+1.93%）更好。照上表刪會刪掉美股的第二名。
**建議保留全部、在論文中揭露相關結構**，符合本研究「不預先窄化、讓資料回答」的原則。

## 6. 限制

- 選股重疊只用**一個代表性 F 組合**計算（各取該市場 C 覆蓋最完整者）。
  不同 F 組合下的重疊度會有差異，這裡是單一樣本。
- 績效相關用的是 **C 增益**（相對同 F 的 None 基準），已控制 F，但仍是 in-sample。
- 本文只涵蓋 openSec 變體。美股的 strict/relaxed/all 尚未在 A1 修正後重跑。
