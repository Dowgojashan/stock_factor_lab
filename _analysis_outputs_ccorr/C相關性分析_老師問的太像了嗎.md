# 20 個 C 是不是太像了？（台股 + 美股）

> **執行日期**：2026-08-15（台股）／2026-08-14（美股）
> **問題來源**：2026-08-05 指導教授 meeting，老師直接問「這些 C **是不是太像了**」
> **變體**：openSec｜**資料**：台股 4,599 策略／219 F 組合；美股 3,948 策略／188 F 組合
> **執行腳本**：`code/c_correlation.py`（**不需重跑回測**）
> **原始資料**：`{TW,US}_openSec_C_corr.csv` / `_C_jaccard.csv` / `_C_similarity.png`
>
> ⚠️ 2026-08-15 更新：台股在資料回補後重算，**結論方向不變但拆解結果有修正**——
> 先前「台股由因子主導、美股由規則主導，兩者完全相反」的說法過度簡化，見 §3。

---

## 1. 怎麼量「像不像」

用兩個互補的指標：

| 指標 | 量什麼 | 為什麼需要 |
|---|---|---|
| **選股重疊**（Jaccard） | 兩個 C 實際選到的股票有多少是同一批 | 最直接的「像」，與報酬無關 |
| **績效相關**（Spearman） | 兩個 C 套在同一批 F 組合上，增益是否同向 | 回答「換一個 C 有沒有實質差別」 |

Jaccard＝交集/聯集，對持股數差很多的配對比較公允。

---

## 2. 答案：**沒有想像中那麼像，但有明確的重複結構**

```
              中位     p90     最高
台股 績效相關  0.341   0.676   0.908
台股 選股重疊  0.303   0.511   0.822
美股 績效相關  0.089   0.752   0.954
美股 選股重疊  0.036   0.644   0.993
```

**中位數都在 0.34 以下**——如果 20 個 C 真的是同一個東西，這兩個數字應該逼近 1。
但**最高的幾對確實到 0.8~0.99**，代表有具體的重複，不是均勻地都有點像。

**美股是極端的雙峰**：整體幾乎不相關（選股重疊中位 0.036），
但最像的那幾對幾乎完全相同（0.993）。台股則是普遍中等相關。

---

## 3. 重複來自哪裡：兩個市場的主導維度不同 ⭐

把配對拆成三類：

### 績效相關（中位數）

| 配對類型 | 對數 | 台股 | 美股 |
|---|---|---|---|
| 同因子 · 不同規則 | 57 | 0.449 | **0.003** |
| 同規則 · 不同因子 | 19 | **0.517** | **0.648** |
| 都不同 | 114 | 0.274 | 0.061 |

### 選股重疊（中位數）

| 配對類型 | 對數 | 台股 | 美股 |
|---|---|---|---|
| 同因子 · 不同規則 | 57 | **0.403** | 0.022 |
| 同規則 · 不同因子 | 19 | 0.317 | **0.595** |
| 都不同 | 114 | 0.287 | 0.017 |

### 怎麼讀這張表

**美股：規則完全主導，而且差距懸殊。**
```
同規則不同因子  績效 0.648／選股 0.595
同因子不同規則  績效 0.003／選股 0.022   ← 幾乎零
```
在美股，`ROE_qmax4` 和 `EPS_qmax4` 選到幾乎同一批股票，
但 `ROE_qmax4` 和 `ROE_yoy` 幾乎毫無關係。**「用哪條規則」決定一切。**

**台股：兩個維度勢均力敵，沒有單一主導者。**
```
績效相關  同規則 0.517 略高於 同因子 0.449
選股重疊  同因子 0.403 略高於 同規則 0.317
```
兩個指標指向相反方向、且差距都在 0.1 以內。**台股的 C 是「因子與規則各貢獻一半」。**

> ⚠️ **這裡修正了先前的說法。** 2026-08-10 用含假值的資料算出台股
> 「同因子 0.556 ＞ 同規則 0.421」，當時寫成「台股由因子主導、與美股完全相反」。
> 資料回補後台股的兩個維度變得接近，**「完全相反」過度簡化了**。
> 正確的說法是：**美股單一維度（規則）主導，台股沒有單一主導維度。**

## 4. 具體哪幾對該注意

### 美股：`qmax` 家族跨因子塌縮成一個 ⭐

```
C10 EPS_qmax4   ↔ C3  ROE_qmax4     Jaccard 0.993   ← 不同來源因子，選同一批股票
C11 EPS_qmax8   ↔ C4  ROE_qmax8             0.989
C17 FCF_P_qmax4 ↔ C18 FCF_P_qmax8           0.989
C10 EPS_qmax4   ↔ C17 FCF_P_qmax4           0.975   ← 連 FCF_P 都塌進去
```

**可能的機制（假說，未驗證）**：`qmax` 問的是「這家公司是不是處在近 4/8 季的高點」。
美股企業的 ROE / EPS / FCF 高度同步（同一個獲利週期），三個因子會在**同一時點**觸發，
規則就蓋過了因子的差異。台股三個序列的同步性較低，因子的差異才留得住。

### 台股：最像的是「同規則、ROE↔EPS」

```
C1  ROE_riseq1  ↔ C8  EPS_riseq1     績效相關 0.908
C5  ROE_yoy     ↔ C12 EPS_yoy                0.903
C2  ROE_riseq2  ↔ C9  EPS_riseq2             0.876
C13 EPS_ytdavg… ↔ C14 EPS_ytdavg…            0.855   ← 同因子、規則只差比較基準
```

台股的重複集中在 **ROE 與 EPS 這兩個獲利面因子之間**（兩者本來就高度相關），
而不是像美股那樣連 FCF_P 都一起塌縮。

---

## 5. ⭐ 這解釋了 Phase 3 的一個謎團

美股 20 個 C 只有 **7 個增益為正**，而那 7 個正好是 `C14` + 六個 `qmax`。

既然六個 `qmax` 實質上是同一個條件，**美股實際上只有 2 種有用的 C**：
```
C14  ytdavg_gt_lyavg    +0.79%
qmax（六個算一個）       +0.04% ~ +0.25%
其餘 13 個              −0.53% ~ −19.36%
```

台股完全不是這樣：**14/20 為正**，最好的 `C4_ROE_qmax8` 增益 **+6.52%**、
增益為正比例 98.2%，而且分界線是「來源因子」（ROE/EPS 全正、FCF_P 全負）。

---

## 6. 怎麼回答老師

> **「有重複，但不是全部。20 個 C 是 3 個來源因子 × 7 種規則。
> 在美股，重複集中在 `qmax` 家族——六個 `qmax` 跨因子塌縮成一個（選股重疊 0.993）；
> 在台股，重複集中在 ROE↔EPS 的同規則配對（相關 0.9）。
> 但整體的中位相關只有 0.34（台股）與 0.09（美股），不是同一個東西。」**

### 三層反證：C 確實不是同一個東西

1. **排名不同**：兩市場 20 個 C 的增益排名 Spearman 僅 **0.272**
2. **有效數量不同**：台股 14/20 為正，美股 7/20（實質 2 種）
3. **相似結構不同**：美股由規則單一主導，台股兩維度勢均力敵

### 若老師要求精簡

保守的刪減建議（20 → 14）：刪掉 `qmax8`（保留 `qmax4`）與
`ytdavg_gt_lyytdavg`（保留 `ytdavg_gt_lyavg`）兩組共 6 個。

⚠️ **但先別急著刪**：台股增益最高的是 `C4_ROE_qmax8`（+6.52%）、
美股最高的是 `C14_EPS_ytdavg_gt_lyavg`（+0.79%）——
**兩個市場的第一名剛好分別落在上面兩組「重複」裡的不同邊**。照上表刪會刪掉台股的第一名。

建議**保留全部、在論文中揭露相關結構**，而不是事前刪減——
這也符合本研究一貫的「不預先窄化、讓資料回答」原則。

---

## 7. 限制

- 選股重疊只用**一個代表性 F 組合**計算（各取該市場 C 覆蓋最完整者）。
  不同 F 組合下的重疊度會有差異，這裡是單一樣本。
- 績效相關用的是 **C 增益**（相對同 F 的 None 基準），已控制 F，但仍是 in-sample。
- §4 的機制是**假說**，尚未用 ROE/EPS/FCF_P 三個序列的實際同步性驗證。
  若要驗證：算三者在各市場的橫斷面相關隨時間的變化。
