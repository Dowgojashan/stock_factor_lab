# 封存：strict 線的 Phase 3/4 舊版（203 個 F 組合，舊基準白名單）

封存日期：2026-08-09

## 為什麼封存

這兩個目錄（`TW_L3_M` / `TW_L4_M`，各 4,263 個策略）是用
**「strict 變體 + 舊基準 4.71%（外部價格指數）」**產生的 **203 個 F 組合**白名單跑的。

後來查證 `taiex` 表是**價格指數、不含股利**，而策略用的是**還原價、含股利**，
基準因此改為**自建宇宙基準 8.67%**（見 `universe_benchmark.py`）。
新基準下 strict 的合格 F 組合只剩 **99 個**。

### 結果本身沒有錯，但目錄意義不對稱

- 分析時已正確篩到 99 個子集（99 ⊂ 203，經驗證無遺漏），**先前報告的數字是對的**
- 但這個目錄「多裝了 104 個在新基準下不合格的組合」，
  而對照組 `TW_L3_relaxed_M` 卻剛好只有 187 個、沒有多餘
- 兩條線的資料夾是用**不同時期、不同判準的白名單**建立的，光看名稱看不出來

為了讓論文的資料流程乾淨可追溯，已用正確的 99 白名單**重跑** strict 線，
新結果放回 `results_artifacts/TW_L3_M` 與 `TW_L4_M`。
