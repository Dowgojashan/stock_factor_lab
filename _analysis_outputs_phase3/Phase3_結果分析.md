## 1. 方法：控制 F 之後才看 C

老師的指示：

> 「[F1×F2] OK 了以後，我就直接去檢查 C」——**F 定案後才碰 C**，
> 避免同時挑 F 和 C 造成雙重選擇偏誤。

**核心作法**：每個 F 組合都有自己的 **None 基準**（同 F、不加 C），
C 的價值 = 該 C 相對**同一個 F 組合**的 None 基準的 CAGR 增益。

這才是「控制 F 之後看 C」，不是把所有 C 混在一起平均——後者正是論文 4-15 的反例。

### 老師的兩個**互相獨立**的約束

> 「這個剩下的不可以太少…不然後面就沒有 LLM 的必要」→ 策略數
> 「但是裡面被選出來的[股票]不能太少，那就是策略不[穩定]」→ 每策略持股數

```
台股 openSec  4,599 策略 → 持股數 < 10 被剔除後，Candidate 池 …
美股 openSec  3,948 策略 → 1,562 個（39.6%）被剔除，Candidate 池 2,334 個（59.1%）
```

## 2. ⭐ 最重要的發現：同一套 C，兩個市場天差地別

### 台股：20 個 C 有 14 個為正，最好的 +6.52%

| C | 來源 | 增益中位數 | 增益為正比例 | 持股數中位 |
|---|---|---|---|---|
| **C4_ROE_qmax8** | ROE | **+6.52%** | **98.2%** | 29.2 |
| C11_EPS_qmax8 | EPS | +4.99% | 95.4% | 33.5 |
| C5_ROE_yoy | ROE | +3.76% | **100.0%** | 87.3 |
| C3_ROE_qmax4 | ROE | +3.50% | 93.2% | 50.9 |
| C12_EPS_yoy | EPS | +3.49% | **100.0%** | 92.6 |
| C9_EPS_riseq2 | EPS | +3.14% | 99.5% | 89.4 |
| …（ROE/EPS 衍生的 14 個全為正） | | | | |
| C17_FCF_P_qmax4 | FCF_P | −3.00% | 12.3% | 41.4 |
| C18_FCF_P_qmax8 | FCF_P | −3.32% | 22.4% | 21.6 |

**台股的分界線是「來源因子」**：ROE / EPS 衍生的 14 個 C **全部為正**，
FCF_P 衍生的 6 個**全部為負**。

### 美股：只有 7 個為正，最好的僅 +0.79%，最差的 −19.36%

| C | 來源 | 增益中位數 | 增益為正比例 | 持股數中位 |
|---|---|---|---|---|
| C14_EPS_ytdavg_gt_lyavg | EPS | **+0.79%** | 65.4% | 104.8 |
| C11_EPS_qmax8 | EPS | +0.25% | 68.6% | 185.6 |
| C10_EPS_qmax4 | EPS | +0.21% | 76.1% | 188.0 |
| C4_ROE_qmax8 | ROE | +0.19% | 67.6% | 185.3 |
| C3_ROE_qmax4 | ROE | +0.15% | 69.1% | 187.8 |
| C17/C18_FCF_P_qmax4/8 | FCF_P | +0.06% / +0.04% | 57% / 59% | 186 |
| …（以下 13 個為負） | | | | |
| C5_ROE_yoy | ROE | −10.04% | 3.2% | **6.3** |
| C2_ROE_riseq2 | ROE | −12.64% | 2.7% | **4.9** |
| C1_ROE_riseq1 | ROE | −17.12% | **0.0%** | **3.5** |
| C8_EPS_riseq1 | EPS | −19.29% | 0.5% | **3.6** |
| C15_FCF_P_riseq1 | FCF_P | −19.36% | 0.5% | **3.7** |

**美股的分界線是「規則型別」**，不是來源因子：
```
qmax / ytdavg 類（7 個）→ 持股 90~188 檔，增益 +0.04% ~ +0.79%
riseq / yoy 類（9 個）  → 持股 3.5~7 檔，增益 −10% ~ −19%
```

### 機制：`riseq`/`yoy` 在美股把持股數壓垮

```
增益為正的 C   → 持股數中位 90 ~ 188 檔
增益 −10~−19% 的 C → 持股數中位 3.5 ~ 7 檔
```

**這些 C 在美股把持股壓到剩 4 檔——不是在選股，是在賭。**
台股同樣的 C 卻保住 85~92 檔並帶來正增益。

> 📌 **老師堅持的「持股數不能太少」約束，在美股剔除了 39.6% 的策略，
> 而被剔除的正是這批。這個約束不是形式上的，它抓到了真問題。**

### 兩市場的 C 排名幾乎不相關

```
20 個 C 的增益排名 Spearman = 0.272
```

**同一套動態條件不能跨市場沿用。** 這是本階段最強的結論，
另有兩層旁證見 `_analysis_outputs_ccorr/C相關性分析_老師問的太像了嗎.md`。

## 3. C 的相似性：老師問的「是不是太像了」

老師當場問過這 20 個 C「是不是太像了」。答案：**沒有想像中那麼像，但有明確的重複結構**，
而且台美的重複結構**方向相反**：

```
台股  由「用哪個因子」主導（同因子不同規則 相關 0.556）
美股  由「用哪條規則」主導（同規則不同因子 相關 0.648），qmax 家族跨因子塌縮（Jaccard 0.993）
```

完整分析見 `_analysis_outputs_ccorr/C相關性分析_老師問的太像了嗎.md`。
