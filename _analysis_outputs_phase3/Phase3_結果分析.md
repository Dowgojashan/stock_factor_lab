## 1. 方法：控制 F 之後才看 C

老師的指示：

> 「[F1×F2] OK 了以後，我就直接去檢查 C」——**F 定案後才碰 C**，
> 避免同時挑 F 和 C 造成雙重選擇偏誤。

**核心作法**：每個 F 組合都有自己的 **None 基準**（同 F、不加 C），
C 的價值 = 該 C 相對**同一個 F 組合**的 None 基準的 CAGR 增益。
這才是「控制 F 之後看 C」，不是把所有 C 混在一起平均——後者正是論文 4-15 的反例。

### 老師的兩個**互相獨立**的約束

> 「這個剩下的不可以太少…不然後面就沒有 LLM 的必要」→ 策略數
> 「但是裡面被選出來的[股票]不能太少，那就是策略不[穩定]」→ 每策略持股數

```
台股 openSec  4,599 策略 → Candidate 池 4,495（持股中位 77.8 檔）
美股 openSec  3,948 策略 → Candidate 池 3,860（持股中位 85.1 檔）
```

> 📌 修正 A1 之後，**兩個市場的持股數都正常了**（中位 78~85 檔）。
> 先前美股出現「C 把持股壓到 3.5 檔」的現象是 bug，不是市場特性。

### 怎麼解讀

**台股靠「創新高」，美股靠「年增」。**

- 台股：`ROE` 創近 8 季新高 → +6.86%。這是**動能型**的訊號，與 Phase 1「台股 MOM 過關、單調↑」一致。
- 美股：`EPS` 較去年同季成長 → +2.68%，而 `ROE` 創新高反而有害。美股 Phase 1 的 `MOM` 是**反轉**（最佳桶 qb0），這裡的「創新高反而不好」與之呼應。

**兩個市場的動能／反轉性質相反，連帶讓最佳動態條件也相反。** 這比「某個市場的 C 沒用」有意義得多——
它說的是**同一種規則在不同市場代表不同的經濟意涵**。

## 5. 🔴 為什麼本文被全面改寫：A1 資料對齊缺陷

### 5.1 症狀

先前版本的美股 C 通過率是病態的兩極：

| C 家族 | 台股（修正前） | 美股（修正前） | 合理值 |
|---|---|---|---|
| `riseq1` | 44.9% | **0.8%** | ~50% |
| `yoy` | 39.9% | **3.2%** | ~50% |
| `qmax4` | 23.3% | **97.5%** | ~25% |
| `qmax8` | 10.7% | **94.1%** | ~12% |

`qmax` 幾乎恆真 ≈ 等同沒有條件；`riseq`/`yoy` 幾乎恆假 ≈ 選不到股票。

### 5.2 根因

`condition_factory._compress_report_updates` 用**面板層**壓縮還原「公告更新點」：

```python
q = df.where(df.ne(df.shift(1))).dropna(how="all").ffill()
#                                ↑ 只要「任一家公司」值有變就保留整列
```

- **台股**：`format_data.adjust_index_of_report` 把財報索引改寫成 5/15、8/31、11/15、3/31
  四個法定期限，**全市場共用同一組日期** → 壓縮後每年 4 列 → `shift(1)` 是真的上一季 ✅
- **美股**：用真實 `filing_date`（前視防護的核心設計），各公司公告日分散
  → 壓縮後每年 **246 列**（≈每個交易日一列）
  → `shift(1)` 變成「前一個交易日」，絕大多數公司值沒變 → 恆假
  → `rolling(4).max()` 變成近 4 個交易日 → 當期必為最大 → 恆真

**這套條件是照台股的資料版面寫的，在美股的真實公告日版面下靜默失效。**
諷刺的是，讓美股更嚴謹的那件事（用真 filing date）正是壓垮它的原因。

### 5.3 修法

`Data.get()` 對財報做了一次 `ffill`（get_data.py:136），ffill 之後就看不出
「這天有沒有新財報」。修正的作法是**同一個欄位提供兩種 frame**：

```
q_band（橫斷面）        → MarketData.get_field()      密集，每列要有完整同儕才排得了名
riseq/qmax/yoy/ytdavg  → MarketData.get_field_ann()  稀疏，每個非 NaN 就是一次真實財報
```

分派由 `condition_factory.ANNOUNCEMENT_TYPES` 決定。**未修改 `get_data.py` / `format_data.py`**。
