## 1. 這一關在回答什麼問題

老師的順序要求：

> 「[F1×F2] **OK 了以後，我就直接去檢查 C**」

先定 F、再測 C，避免同時挑兩者造成雙重選擇偏誤
（老師：「如果三個因子都作弊，應該會有不少快 40」）。

**分析方法的關鍵**：每個 F 組合都有自己的 **None 基準**（同 F、不加 C），
C 的價值 = 相對**同一個 F 組合**的增益。
這才是「控制 F 之後看 C」——把所有 C 混在一起平均正是論文 4-15 的反例。

**C 構面沒有預先刪減**：雖然 Phase 1 顯示 FCF_P 沒訊號，仍保留全部 20 個 C，
讓資料自己回答（依使用者指示「沒有明顯拖累過頭的就全部先跑一跑」）。

## 3. 五個主要發現

### 發現一：C 的價值遠大於 F2 ⭐⭐

```
Phase 2  加 F2 ：增益中位數 −0.04%，為正比例 49.0%   → 期望值是零
Phase 3  加 C  ：最佳 C +5.07%，20 個裡有 18 個中位數為正
```

**同樣是「多加一個構面」，F2 幾乎沒用，C 卻能穩定加分 2~5 個百分點。**

這對整個 FCV 架構是重要的定位資訊：**C（動態條件／趨勢）才是真正的加值來源，
F2（第二個橫斷面因子）多半是冗餘的**。也再次呼應老師說的「F2 可以是空集合」。

> 📌 若要精簡架構，砍 F2 的代價遠低於砍 C。

### 發現二：同一條規則套在不同因子上，結果天差地別 ⭐⭐⭐

**「近 8 季最高」這條規則的三個版本：**

| C | 套在哪個因子 | 增益中位數 | 排名 |
|---|---|---|---|
| **C11** | EPS | **+5.07%** | **第 1** |
| **C4** | ROE | **+4.96%** | **第 2** |
| **C18** | FCF_P | **−2.88%** | **倒數第 1** |

**同一條規則、三個因子，一個全場最強、一個全場最弱。**
「近 4 季最高」也是同樣模式：C10(EPS) +3.03%、C3(ROE) +2.13%、**C17(FCF_P) −2.01%**。

**規則本身沒有問題，問題出在 FCF_P 這個因子。**

這與 Phase 1 完全對得起來：FCF_P 當橫斷面分位因子時 ρ 只有 +0.13、被淘汰；
現在它當動態條件的來源也是唯一中位數為負的。**兩個獨立的檢定得到同一個結論。**

而且這是**第三次**印證：先前 10 批舊實驗就發現「C15~C20 一致墊底」，
當時不知道原因，現在知道了。

### 發現三：MIN_HOLDINGS 這道防線終於發揮作用，而且抓到了真的陷阱 ⭐⭐

Phase 2 時因為 3 桶持股太多（中位數 162 檔），這道防線只擋掉 3 個。
Phase 3 加了 C 之後持股數中位數降到 **74.1 檔**，防線開始有意義（擋掉 40 個）。

**最具代表性的案例：Phase 2 的冠軍組合 `P_IC_qb0 × PB_qb2`。**

它在 Phase 2 的 CAGR 26.31%、平均持股 18 檔（我當時已標記「集中度風險高」）。
到了 Phase 3，它的 21 個 C 變體中：

| C | CAGR | 平均持股 |
|---|---|---|
| **C18** | **46.03%** ← 全場最高 | **3.4 檔** ❌ |
| C14 | 36.34% | 9.6 檔 ❌ |
| C12 | 33.91% | 9.5 檔 ❌ |
| C17 | 33.49% | 5.4 檔 ❌ |
| …（其餘 16 個） | | 全部 < 10 檔 ❌ |
| None | 26.31% | 18.0 檔 ✅ |

**20 個 C 變體全部因持股數不足被剔除，只有不加 C 的原型存活。**

如果沒有這道防線，我們會挑中一個「CAGR 46%、但平均只持 3.4 檔股票」的策略——
那不是策略，是賭博。**老師的第二個約束在這裡實實在在擋下了一個過擬合陷阱。**

> 📌 這是可以直接向老師報告的具體成果：您提的「選出的股票不能太少」這個限制，
> 抓到了一個 CAGR 46% 的假象。

### 發現四：MOM 在 Phase 2 是最差的 secondary，在 Phase 3 卻是最好的 primary

Candidate 池 Top 15 裡有 **9 個** 的 F 組合含 MOM_qb1/qb2：

```
MOM_qb2 × REVENUE_qb1 + C4   → CAGR 36.95%（全場最高）｜持股 31.8
MOM_qb2 × DEBTRATIO_qb2 + C4 → CAGR 36.71%           ｜持股 32.7
MOM_qb2 × DEBTRATIO_qb2 + C3 → CAGR 31.40%           ｜持股 55.9
```

對照 Phase 2 的發現（MOM 當 secondary 增益中位數 **−2.72%**，全場最差），
**同一個因子，當主訊號很強、當配角很差。**

原因：MOM 本身是強訊號（Phase 1 ρ=+0.93），但它與估值因子方向相反
（動能強的股票通常不便宜），拿去當配角只會抵銷主訊號。

> 📌 這再次強化 Phase 2 的核心洞察：**「單因子強度」與「配對價值」是兩件事**，
> 而且現在多了一層——**角色（primary vs secondary）決定了一個因子有沒有用**。

### 發現五：C 也會收窄持股數，強的 C 收得更兇 ⚠️

```
None（不加 C）    持股中位數 162 檔（Phase 2 數字）
全部 C 平均後      持股中位數  74 檔
C4  (ROE近8季最高) 持股中位數  27 檔
C11 (EPS近8季最高) 持股中位數  31 檔
```

**增益最大的兩個 C，也是收窄最兇的兩個。** 這不是巧合——
「近 8 季最高」是很嚴格的條件，能通過的公司本來就少。

**這代表 C 的增益有一部分來自「選得更精」，而不只是「選得更對」。**
到 Phase 4 加上 V 之後會再收窄一次，屆時 MIN_HOLDINGS 會擋掉更多，需要留意。

## 4. 老師的兩個獨立約束：現況

| 約束 | 老師原話 | 現況 |
|---|---|---|
| **策略數** | 「剩下的不可以太少…不然後面就沒有 LLM 的必要」 | 4,263 → 篩後 **4,206** ✅ 充足 |
| **每策略持股數** | 「被選出來的[股票]不能太少，那就是策略不[穩定]」 | 中位數 74 檔，40 個 (0.9%) 被剔除 ✅ |

**⚠️ 但候選池的篩選條件太寬鬆：4,206 / 4,263 = 98.7% 都入選。**

因為「CAGR > 大盤 4.71%」這個門檻幾乎擋不住任何東西
（候選池 CAGR 中位數 14.49%、最低 4.72%）。

這與先前舊實驗遇到的問題相同（當時堪用池 28,970 個，遠超「幾千」的甜蜜點）。
**建議在 Phase 4 之後、交給 LLM 之前，加上更實質的第二段篩選**
（例如同時要求 MDD、勝率、交易次數），而不是只看 CAGR。

## 6. 對 Phase 4 的建議

### 帶進 Phase 4
4,206 個 Candidate Strategy，加上 V（v0/v1）對照 → 約 8,400 個策略。

### 建議確認的三件事

1. **候選池篩選條件要收緊**（見 §4）——目前 98.7% 都入選，等於沒篩。
   建議在 Phase 4 後導入多條件篩選（CAGR + MDD + 勝率 + 交易次數）。

2. **C6 的異常值得檢查**：C6（ROE YTD均>去年同期均）增益只有 +0.08%、為正比例 52.2%，
   在 ROE 系裡明顯偏低，但同樣邏輯的 C7（ROE YTD均>去年**全年**均）卻有 +2.98%。
   **兩個定義只差比較基期，結果差 37 倍**，值得確認 C6 的實作是否正確。

3. **FCF_P 衍生的 C15~C20 是否移除**：三個獨立證據都指向它們沒用
   （Phase 1 因子淘汰、Phase 3 唯一負中位數、舊實驗一致墊底）。
   但移除等於用 in-sample 結果再篩一次，需與老師討論。
