## 1. 🔴 基準更正：4.71% → 8.67%

### 發現的問題

查證 `taiex` 表的實際數值（年底值 2000→4,739｜2010→8,972｜2015→8,338｜2024→23,035），
確認它是**台灣加權股價指數（價格指數）**，**不含股利**。

但我們的策略用 TEJ **還原收盤價**（配息已還原），**含股利**。
→ **一直在拿「含息的策略」比「不含息的大盤」。**

⚠️ 美股 `sp500` 表同樣是價格指數（2000→1,320｜2024→5,882），**問題相同**。
資料庫**沒有**任何報酬指數表。

### 解法：自建宇宙基準

用**我們自己的資料**算「什麼都不篩、把宇宙裡的股票全部等權買下來」的績效，
一次消掉三個不對等：

| 不對等 | 外部指數 | 自建基準 |
|---|---|---|
| 股利 | ❌ 不含 | ✅ 同樣用還原價 |
| 宇宙 | 全上市公司 | ✅ 同樣只含有因子資料的 1,775 家 |
| 交易成本 | 無 | ✅ 同樣月頻換股 + 0.1425% + 0.3% |

```
外部指數（價格指數）      = 4.71%
自建宇宙基準              = 8.67%
                    差距 = +3.96pp   ← 先前被高估的幅度
```

它回答的問題也更貼切：外部指數問「有沒有贏市場」，
自建基準問「**因子篩選有沒有比不篩選更好**」——後者才是本研究要證明的事。

### 對前面各 Phase 的影響

| | 舊基準 4.71% | **新基準 8.67%** |
|---|---|---|
| **Phase 1** 去留名單 | 5過關/2極端/5邊際/7淘汰 | **完全相同**（線性檢定用 ρ，不依賴基準）✅ |
| **Phase 2** 可當 primary 的桶 | 12 | **5** |
| **Phase 2** 晉升組合 | 203 | **99** |
| **Phase 3** 候選池 | 4,206 | 2,033 |

**Phase 1 判定完全不受影響**是個好的穩健性訊號。
Phase 2 幾乎砍半，新基準下只剩最乾淨的 5 個：

```
P_IC_qb0 14.42%｜PB_qb0 14.17%｜EV_S_qb0 13.33%｜PS_qb0 13.06%｜MOM_qb2 11.86%
```

**四個估值因子的「最便宜桶」+ 動量的「最強桶」，每個因子只留一個桶**
——比先前的 12 個桶乾淨得多，也更符合老師說的「primary 一定要是有意義的」。

> 📌 **需與老師確認**：TEJ Pro 有報酬指數（`TaiexImporter.py` 註解明載「加權指數／報酬指數
> 皆同一種版面」），可請 collector 匯出，當作對外的傳統基準。
> 但台灣報酬指數 2003 才發布，2000~2002 沒有官方資料。

## 2. Phase 4：V（估值濾網）該不該加？

### 設計

**只跑 v1**：Phase 3 已把同樣的 F×C 用 v0 跑完，v0 直接沿用，
本階段只補 v1（4,263 個），分析時依「F組合__C」配對比較。**省下約 1.6 小時重複回測。**

V 的定義（沿用學姊論文）：`v1 = PE 低於近4季均值、但高於近4季最低點`
＝「相對自己歷史便宜、但不是最谷底」——買回檔，不接墜落的刀。

### 結果：V1 大多數情況下是有害的

```
ΔCAGR 中位數 −1.84%  ｜ 為正比例僅 35.2%
ΔMDD  中位數 −8.03%  ｜ 風險真的下降的只有 19.7%
持股數  74.4 → 11.6   ← 砍掉 84%
```

**ΔCAGR × ΔMDD 四象限**

| 象限 | 數量 | 佔比 |
|---|---|---|
| ① 報酬升 風險降（雙贏） | 178 | 8.6% |
| ② 報酬升 風險升 | 553 | 26.6% |
| ③ 報酬降 風險降（換取穩定） | 231 | 11.1% |
| **④ 報酬降 風險升（雙輸）** | **1,117** | **53.7%** |

**超過一半落在最差象限。**

> 📌 這幾乎完美複製了先前 10 批舊實驗的發現（當時 55% 在最差象限）。
> **用完全不同的因子池、不同的分桶、不同的基準，得到同一個結論**——互相印證。

### 為什麼 V1 會讓風險變高（反直覺但有解釋）

**V1 把持股數從 74 檔砍到 11.6 檔（−84%）。**

分散度大幅下降 → 回撤反而更深。
**V1 名義上是「風險控管」，實際運作起來是「集中度放大器」。**

### 但 V1 不是完全沒用——它高度條件性

**依 F1 因子**

| F1 | ΔCAGR中位 | ΔMDD中位 |
|---|---|---|
| **EV_S** | **+1.90%** | −15.08% |
| PS | −0.03% | −8.97% |
| **MOM** | −1.76% | **+1.77%** ← 唯一風險真的降低 |
| PB | −2.97% | −8.27% |
| P_IC | −4.89% | −11.25% |

**依 C 分組**

| 最受益 | ΔCAGR | 最受害 | ΔCAGR |
|---|---|---|---|
| C2 (ROE較前2季升) | **+1.40%** | C17 (FCF_P近4季最高) | **−4.98%** |
| C3 (ROE近4季最高) | +1.27% | C16 (FCF_P較前2季升) | −4.87% |
| C7 (ROE YTD>去年全年) | +0.07% | C19 (FCF_P年增) | −4.76% |

**正確的說法不是「V1 沒用」，而是「V1 只在特定 F/C 搭配下划算」**：
- 搭 **EV_S** 當 F1 → 報酬還會上升
- 搭 **MOM** 當 F1 → 報酬降但風險真的降（唯一達成 V 設計初衷的組合）
- 搭 **FCF_P 衍生的 C** → 兩頭空，最該避免

### 最終 Candidate Strategy（v0/v1 合併擇優）

```
3,186 個（v0 2,033 ／ v1 1,153）
CAGR 中位 16.16%｜p90 21.37%｜最高 36.95%
```

**v1 佔 36%** ——雖然 V1 整體是負面的，但仍有超過三分之一的策略是加了 V1 之後才入選，
證明「保留 V0/V1 兩種選擇讓後續挑選」是對的設計，不該一刀切掉 V。

## 3. strict vs relaxed 變體對照

### 設計

| 變體 | primary 池 | 說明 |
|---|---|---|
| **strict** | 5（Phase 1 過關） | 現行 |
| **relaxed** | 12（過關 + 邊際 + 只取極端桶） | 放寬，只排除 Phase 1 淘汰的 7 個 |

⚠️ **執行上的一個坑（已修正）**：Phase 3 最初是用 strict 規則下的 203 白名單跑的，
而 relaxed 的 187 個組合裡有 **57 個（30%）不在那 203 裡、從未跑過 C**。
第一次做出來的 relaxed 數字是**不完整、不可比**的。
已補跑 `TW_L3_relaxed_M` / `TW_L4_relaxed_M`（各 3,927 策略，共 2.1 小時），
本節數字為補齊後的公平對照。

### 結果：放寬只增加數量，不增加品質 ⭐⭐

| | strict | relaxed | 變化 |
|---|---|---|---|
| Phase 2 可當 primary 的桶 | 5 | 14 | +180% |
| Phase 2 晉升組合 | 99 | 187 | +89% |
| **最終 Candidate 數** | **3,186** | **6,016** | **+89%** |
| **CAGR 中位數** | **16.16%** | **14.96%** | **−1.20pp** ↓ |
| **CAGR p90** | **21.37%** | **20.24%** | **−1.13pp** ↓ |
| **CAGR 最高** | **36.95%** | **36.95%** | **完全相同** |
| MDD 中位數 | −55.60% | −56.71% | 略差 |

**Top 5 完全一模一樣：**

```
1. MOM_qb2 × REVENUE_qb1   + C4  (v0)  36.95%
2. MOM_qb2 × DEBTRATIO_qb2 + C4  (v0)  36.71%
3. PS_qb0  × REVENUE_qb1   + C7  (v1)  34.84%
4. EV_S_qb0 × ROIC_qb2     + C7  (v1)  32.26%
5. PS_qb0  × REVENUE_qb1   + C14 (v1)  32.11%
```

### 結論

**放寬 primary 門檻多找出 2,830 個候選策略，但沒有產生任何一個更好的策略，
反而把中位數與 p90 都拉低了。**

多出來的全是**比 strict 已經找到的更差**的策略。

> 📌 **這是對老師方法論的直接驗證，而且結果支持嚴格版。**
> 老師說「primary 一定要是有意義的」——資料顯示，把不夠格的因子升格為主訊號，
> 只會稀釋策略池的品質，不會發掘出新的好東西。
>
> 這也回答了「你怎麼知道你篩掉的是壞的？」這個必然會被問到的問題。

⚠️ **但這還不是完整的對照。** 真正的對照組是 `all` 變體
（19 個因子全下、完全不做 Phase 1 篩選），它才能回答
「被 Phase 1 **淘汰**的因子是否真的沒用」。relaxed 只放寬到「邊際」，
淘汰的 7 個仍未進場。**建議接著跑 `all` 變體。**
