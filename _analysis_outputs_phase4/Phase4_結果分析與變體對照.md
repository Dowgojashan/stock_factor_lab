## 1. V 的定義與設計

沿用學姊論文：
```
v1 = PE 低於近 4 季均值、但高於近 4 季最低點
   ＝「相對自己歷史便宜、但不是最谷底」——買回檔，不接墜落的刀
```

**只跑 v1**：Phase 3 已把同樣的 F×C 用 v0 跑完，v0 直接沿用，本階段只補 v1，
分析時依「F組合__C」配對比較，**省下約一半的重複回測**。

> ℹ️ `get_v_mask` 用 `resample("QE")` 做真正的日曆季重取樣，
> **不受 A1 那個資料對齊缺陷影響**（該缺陷只影響 `condition_factory` 的季語意條件）。

## 2. ⭐ 結果：V1 在兩個市場都有害，而且美股更嚴重

| | 台股 | 美股 |
|---|---|---|
| ΔCAGR 中位數 | **−1.96%** | **−5.74%** |
| ΔCAGR 為正比例 | 27.9% | **9.8%** |
| 持股數 v0 → v1 | 77.2 → **12.6** | 84.1 → **19.7** |

### 四象限（論文 4-21）

| 象限 | 台股 | 美股 |
|---|---|---|
| ① 報酬升 風險降（雙贏） | 634（13.8%） | 155（**3.9%**） |
| ② 報酬升 風險升 | 647（14.1%） | 231（5.9%） |
| ③ 報酬降 風險降（換取穩定） | 1,108（24.1%） | 688（17.4%） |
| **④ 報酬降 風險升（雙輸）** | **2,210（48.1%）** | **2,874（72.8%）** |

**美股有近四分之三的策略是純粹雙輸**，台股接近一半。

### 為什麼 V1 有害：它砍掉 76~84% 的持股

```
台股 持股中位  77.2 → 12.6   （−84%）
美股 持股中位  84.1 → 19.7   （−77%）
```

V1 是一個**相當嚴格的額外交集**。在已經有 F1×F2×C 三層過濾之後再加一層，
選出的股票太少、分散度崩潰——**這正是老師「持股數不能太少」的約束想防的事**。

> 📌 **跨市場一致**是這個結論最可靠的地方。台美的因子、C、規模效應都不同
> （C 排名相關僅 0.149），唯獨 V1 有害在兩邊完全一致。

### ⚠️ 一個尚未處理的資料限制

`get_v_mask` 的唯一依據是 `PE`，而美股 PE 有 **31.45% 是負值**（虧損公司，真實資料）。
對負 PE 而言「PE 低於近 4 季均值」＝**虧得更兇**，與「變便宜」意思相反
→ V 濾網對美股三分之一的觀測**語意是壞的**。

**但這不會推翻結論**：台股的 PE 幾乎沒有負值（2 筆，TEJ 對虧損公司直接留白），
語意完全正常，而**台股的 V1 一樣有害**。台股在此扮演乾淨的對照組。

另外 `PE` 本身尚未清理（max 1.377e17），已列入 collector 待辦。

**Top 6 全部是 v0**，兩個市場都是——再次印證 V1 有害。

### 三個要在論文誠實交代的

**1. 台股 Top 策略的持股數偏低（11~25 檔）**，卡在 `MIN_HOLDINGS = 10` 附近。
第 4 名（48.1 檔）與第 6 名（20.7 檔、MDD 僅 −39.80%）分散度好得多，更適合實際部署。

**2. 美股排行榜仍被 `REVENUE_qb0` 主導**（Top 6 有 5 個），而規模控制顯示
`REVENUE_qb0` 用真市值控制後在大型股是 **−6.76%**（規模混淆）。
見 `_analysis_outputs_sizecontrol/規模控制分析.md`。
**新的第一名 `PB_qb0 × EPS_qb0` 不含 `REVENUE`**，兩隻腳在規模控制下都撐得住，
是更可靠的代表策略。

**3. 美股宇宙有嚴重倖存者偏誤**（99.5% 是活到 2026 的公司），
68.94% 應視為**上界**。見 `美股結果總覽.md` §8。

## 4. A1 修正對本階段的影響

| | 修正前 | 修正後 |
|---|---|---|
| 台股最終候選 | 7,130 | 7,162（+0.4%） |
| 台股 CAGR 中位 | 15.40% | 15.53% |
| 台股最高 | 33.79% | 33.54% |
| **美股最終候選** | 4,505 | **6,916（+53.5%）** |
| 美股 CAGR 中位 | 22.96% | 23.61% |
| **美股最高** | 58.39% | **68.94%（+10.55pp）** |
| 美股 ④ 雙輸比例 | 59.0% | **72.8%** |

**台股幾乎不動、美股大幅改變**——與 A1 的診斷完全一致（台股靠「全市場同一天公告」
碰巧不受影響，美股才是受害者）。美股候選數暴增 53.5%，是因為修正前
`riseq`/`yoy` 恆假、那 9 個 C 產生的策略幾乎全部持股不足被剔除。
