## 1. V 的定義與設計

沿用學姊論文：
```
v1 = PE 低於近 4 季均值、但高於近 4 季最低點
   ＝「相對自己歷史便宜、但不是最谷底」——買回檔，不接墜落的刀
```

**只跑 v1**：Phase 3 已把同樣的 F×C 用 v0 跑完，v0 直接沿用，本階段只補 v1，
分析時依「F組合__C」配對比較，**省下約一半的重複回測**。

## 2. ⭐ 結果：V1 在兩個市場都有害

| | 台股 | 美股 |
|---|---|---|
| ΔCAGR 中位數 | **−1.80%** | **−4.41%** |
| ΔCAGR 為正比例 | 29.5% | 13.0% |
| 持股數 v0 → v1 | 77.1 → **12.6** | 75.4 → **17.9** |

### 四象限（論文 4-21）

| 象限 | 台股 | 美股 |
|---|---|---|
| ① 報酬升 風險降（雙贏） | 640（13.9%） | 382（9.7%） |
| ② 報酬升 風險升 | 719（15.6%） | 131（3.3%） |
| ③ 報酬降 風險降（換取穩定） | 1,040（22.6%） | 1,107（28.0%） |
| **④ 報酬降 風險升（雙輸）** | **2,200（47.8%）** | **2,328（59.0%）** |

**接近一半（台股）到六成（美股）的策略是「報酬降、風險還升」的純粹雙輸。**

### 為什麼 V1 有害：它砍掉了 84% 的持股

```
台股 持股數中位  77.1 → 12.6   （−84%）
美股 持股數中位  75.4 → 17.9   （−76%）
```

V1 是一個**相當嚴格的額外交集**。在已經有 F1×F2×C 三層過濾之後再加一層，
選出的股票太少，分散度崩潰——**這也正是老師「持股數不能太少」約束想防的事**。

> 📌 **跨市場一致**是這個結論最可靠的地方。台美的因子、C、規模效應都不同，
> 唯獨 V1 有害在兩邊完全一致。

### ⚠️ 一個尚未處理的資料限制

`get_v_mask` 的唯一依據是 `PE`，而美股 PE 有 **31.45% 是負值**（虧損公司，真實資料）。
對負 PE 而言，「PE 低於近 4 季均值」＝**虧得更兇**，與「變便宜」意思相反
→ V 濾網對美股三分之一的觀測**語意是壞的**。

**但這不會推翻結論**：台股的 PE 幾乎沒有負值（2 筆，TEJ 對虧損公司直接留白），
語意完全正常，而**台股的 V1 一樣有害**。台股在此扮演乾淨的對照組。

建議在論文中列為限制，並可考慮之後測一個變體（v1 只套用在 PE > 0 的公司）。

### 兩個要在論文誠實交代的

**1. 台股的 Top 策略持股數偏低（10~15 檔）。**
剛好在 `MIN_HOLDINGS = 10` 的門檻邊緣。這些策略雖然通過約束，
但分散度低、對個股風險敏感，不應該當成唯一的推薦標的。

**2. 美股的排行榜頂端被單一 F 組合壟斷。**
前 11 名有 10 個是 `REVENUE_qb0 × PS_qb0`，只是換不同的 C。
規模控制分析已確認這是「小型股放大效果」而非「效果來自小型股」
（見 `_analysis_outputs_sizecontrol/規模控制分析.md`），但報數字時應同時報中大型層的版本。

## 4. 依 C 分組：哪些 C 加了 V1 特別糟

**台股**：加 V1 後 ΔCAGR 最差的是 `yoy` 與 `riseq2` 類；
**美股**：最差的是 `C19_FCF_P_yoy`（−8.51%）、`C12_EPS_yoy`（−7.49%）。

兩市場一致的型態是：**本來就會壓低持股數的 C，再加 V1 會雪上加霜**。
