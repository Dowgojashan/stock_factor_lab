## 1. 為什麼要三個基準

三個基準回答的是**三個不同的問題**，不是同一個東西的三種算法：

| 基準 | 它在問什麼 | 含股利 | 權重 | 宇宙 |
|---|---|---|---|---|
| 外部**價格**指數 | （不該用）| ❌ | 市值 | 全上市 |
| 外部**報酬**指數 | 「有沒有贏傳統的市場報酬」 | ✅ | 市值 | 指數成分股 |
| **自建宇宙基準** | 「**因子篩選有沒有比不篩選更好**」 | ✅ | 等權 | 同策略母體 |

**正式版主基準是自建宇宙基準**——因為本研究要證明的是「篩選有價值」，
不是「打敗大盤」。報酬指數留給論文做對外的傳統對照。

## 3. ⭐ 自建基準的獨立驗證

論文一定會被問：**「你自己算的基準憑什麼可信？」**

現在有了官方報酬指數，可以**獨立驗證**：

```
台股
  股利貢獻 = 報酬指數 12.35% − 同期價格指數 8.41%  = +3.95pp   ← 官方資料算的
  自建基準 − 全期價格指數 = 8.67% − 4.71%          = +3.96pp   ← 我們自己算的
                                            差距 = 0.01pp
```

**我們的自建基準相對價格指數多出來的部分（3.96pp），
與官方報酬指數獨立量到的股利貢獻（3.95pp）幾乎完全一致。**

這證明自建基準的「含息」處理是對的——它不是憑空多出來的報酬，
就是股利，而且量級與官方資料吻合到小數點後兩位。

> 📌 這是個很強的驗證，因為兩邊的資料來源完全獨立：
> 自建基準用 TEJ **個股還原收盤價**逐檔等權模擬，
> 報酬指數是 TEJ 自己編製的**指數**。兩條路算出同一個數字。

### 美股為什麼差這麼多？

```
美股
  股利貢獻 = 8.12% − 6.14%  = +1.98pp
  自建基準 − 價格指數 = 12.35% − 6.14% = +6.21pp
                        無法對上（差 4.23pp）
```

**這個差距是預期中的，而且解釋得通**：台股的自建基準與加權指數的**宇宙相近**
（都是全上市），但美股不是——

| | S&P 500 (TR) | 自建宇宙基準 |
|---|---|---|
| 成分 | **500 家大型股** | **~2,974 家**（Russell 3000 等級） |
| 權重 | 市值加權 | **等權** |

**兩層小型股傾斜**（納入中小型股 + 等權）疊加起來就是那 4.23pp。
這正好也解釋了為什麼美股的規模效應比台股強得多
（見 `_analysis_outputs_sizecontrol/規模控制分析.md`：規模落差中位數台股 +2.1pp、美股 +7.5pp）。

## 4. 論文怎麼寫

建議的敘事順序：

1. 一開始用外部價格指數（學姊論文的作法）
2. 查證後發現它**不含股利**，而策略用還原價含股利 → 不對等
3. 改用自建宇宙基準，同時消掉股利、宇宙、交易成本三個不對等
4. 官方報酬指數到貨後**回頭驗證**自建基準 → 台股差距僅 0.01pp
5. 美股對不上的 4.23pp 有明確解釋（S&P500 是 500 家市值加權 vs 我們 2,974 家等權）

**第 4 步是關鍵**——它把「自己造一個基準」從可疑變成可驗證。
