## 2. Phase 1：因子去留

```
✅ 過關（8）    ：REVENUE, P_IC, VOL, PS, EV_EBITDA, EV_S, PB, EPS
⚠️ 只取極端桶（9）：ACCRUAL, OCF_E, CROIC, FCF_P, ROIC, MOM, REV_G, ROE, DEBTRATIO
⚠️ 邊際（1）    ：NETDEBT_EBITDA
❌ 淘汰（1）    ：FCF_OI
🚫 前瞻偏誤（1） ：MOM1
```

**與台股的關鍵差異**：

| | 台股 | 美股 |
|---|---|---|
| 過關 | 5（PB/PS/P_IC/MOM/EV_S） | **8**（多了 REVENUE/VOL/EV_EBITDA/EPS，少了 MOM） |
| 只取極端桶 | 2 | **9** |
| 形狀 | 多為單調 | **9 個是 U 型（兩端最好）** |

- **`MOM` 在兩市場的角色相反**：台股 ρ=+0.93 單調↑（動能），美股 ρ=−0.05 U 型、
  最佳桶是 **qb0（動能最弱）**——**反轉效應**。
- **美股大量 U 型**：兩端都好、中間差。這是「極端值有訊號、中庸無訊號」的樣態。
- `MOM1` ρ=+1.000、最佳桶 CAGR **70.88%**——前瞻偏誤的完美反面教材（見 Phase 1 台股文件）。

## 4. Phase 3：加 C

```
3,948 個策略（188 F 組合 × 21 種 C 狀態）
持股數 < 10 被剔除：1,562 個（39.6%）
Candidate Strategy 池：2,334 個（59.1%）
```

**只有 7 個 C 的增益中位數為正**，而且那 7 個是 `C14` + 六個 `qmax`
——而 §7 的相關分析顯示六個 `qmax` 實質上是同一個條件，
**所以美股實際只有 2 種有用的 C**。

墊底的 9 個（`riseq1`/`riseq2`/`yoy`）增益 −9% ~ **−19.41%**，
且**把持股數壓到 3.5~6.9 檔**——不是在選股，是在賭。
台股同樣這幾個 C 卻全是正增益。

## 7. C 相關：與台股結構完全相反

```
              中位     最高
台股 選股重疊  0.305   0.802
美股 選股重疊  0.036   0.993   ← 極端雙峰
```

## 8. 殘留的資料雜訊：已量化，可忽略

collector 尚未完成的清理（約 1,150 家未套用防呆重算、約 1,251 筆真假不明，
因 FMP 額度用盡中斷）對本結果的影響：

**關鍵**：`q_band` 用 `rank(pct=True)` 排序分桶，值的大小不影響，只影響排序位置。
爛值幾乎全往「上尾」跑（分母極小正數 → +huge），而估值因子我們**全部用 qb0**。

我們實際在用的 8 個 primary 桶，該側離群率：
```
REVENUE_qb0 0.000% ｜ VOL_qb2 0.000% ｜ P_IC_qb0 0.002% ｜ PS_qb0 0.016%
EV_S_qb0    0.021% ｜ PB_qb0  0.145% ｜ EV_EBITDA_qb0 0.077% ｜ EPS_qb0 0.607%
                            平均 0.109%
```
美股單因子桶平均持股約 580 檔 → 最壞情況約 **3.5 檔**受汙染（0.6% 的資金）。

**已在 §1 用實跑驗證**：清理前後決策層面沒有任何改變。

### ⚠️ 一個未處理項：`PE` 沒被清，但它有在用

```
PE   n=532,638   min = -5.08e10   max = 1.377e17
```
`PE` 被排除在 F 因子池外（老師 2026-08-05 決定），但它是 **V 估值濾網的唯一依據**
（`fcv_core.MarketData.get_v_mask` 用 `report:pe` 算近 4 季均值/最低）。
一個爛 PE 會汙染該公司**連續 4 季**的 v1 判定，而最終候選有 2,171 個是 v1。

→ **已列入給 collector 的待辦**。影響評估：v1 本來就被判定為有害（§5），
所以即使 v1 有雜訊也不改變「不要用 V1」的結論；但若要在論文中報 v1 的數字，
應先清理。
