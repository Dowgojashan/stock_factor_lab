## 1. 兩次資料事件，兩種結果

美股這條線經歷過兩次「資料/程式出問題 → 重跑」，結論剛好相反，值得對照：

| | collector 資料清理（`_safe_div`、EPS/REVENUE 極端值） | **A1 條件對齊缺陷** |
|---|---|---|
| 影響層 | 因子值 | **C 條件的遮罩** |
| Phase 1 判定 | 完全相同 | 完全相同（不含 C） |
| Phase 2 晉升 | 完全相同（188） | 完全相同（不含 C） |
| **Phase 3/4** | 最終候選 4,498 → 4,505（+7） | **4,505 → 6,916（+53.5%）** |
| 最佳 CAGR | 57.85% → 58.39% | **58.39% → 68.94%** |
| 結論 | **不敏感**（穩健性證據） | **全面改變** |

**為什麼資料雜訊不敏感**：`q_band` 是排序分桶，值錯得多離譜不影響，只影響排在哪裡，
而爛值幾乎全落在我們**不使用**的那一端（見 §8）。

**為什麼 A1 影響巨大**：它不是資料錯，是**條件本身失效**——
`qmax` 恆真（≈ 沒有條件）、`riseq`/`yoy` 恆假（≈ 選不到股票）。
完整診斷見 `_analysis_outputs_phase3/Phase3_結果分析.md` §5。

## 2. Phase 1：因子去留

```
✅ 過關（8）    ：REVENUE, P_IC, VOL, PS, EV_EBITDA, EV_S, PB, EPS
⚠️ 只取極端桶（9）：ACCRUAL, OCF_E, CROIC, FCF_P, ROIC, MOM, REV_G, ROE, DEBTRATIO
⚠️ 邊際（1）    ：NETDEBT_EBITDA
❌ 淘汰（1）    ：FCF_OI
🚫 前瞻偏誤（1） ：MOM1
```

**與台股的關鍵差異**：

| | 台股 | 美股 |
|---|---|---|
| 過關 | **6**（P_IC/PB/PS/EV_S/MOM/ROE） | **8**（REVENUE/P_IC/VOL/PS/EV_EBITDA/EV_S/PB/EPS） |
| 只取極端桶 | **1**（FCF_P） | **9** |
| 邊際 | **7** | 1 |
| 淘汰 | **5** | 1（FCF_OI） |
| 形狀 | 多為單調 | **9 個是 U 型（兩端最好）** |

- 兩市場**共同過關**的是 `P_IC` / `PB` / `PS` / `EV_S` 四個估值因子——最穩固的結論。
- **`MOM` 方向相反**：台股 ρ=+0.93 單調↑（動能），美股 ρ=−0.05 U 型、最佳桶 qb0（**反轉**）。
- **美股大量 U 型**：極端值有訊號、中庸沒有。美股公司分散度大，中段訊號被稀釋。
- `MOM1` ρ=+1.000、最佳桶 **70.88%**——前瞻偏誤的反面教材。

## 4. Phase 3：加 C —— 美股靠「年增」，不是「創新高」

```
3,948 個策略（188 F 組合 × 21 種 C 狀態）
Candidate 池 3,860 個（97.8%）｜持股中位 85.1 檔
```

**13/20 個 C 增益為正**，最好的是 `C12_EPS_yoy`：

| C | 來源 | 增益中位 | 為正比例 | 持股中位 |
|---|---|---|---|---|
| **C12_EPS_yoy** | EPS | **+2.68%** | 82.4% | 97.8 |
| C13_EPS_ytdavg_gt_lyytdavg | EPS | +2.38% | 76.1% | 103.3 |
| C9_EPS_riseq2 | EPS | +1.99% | 77.1% | 97.4 |
| C14_EPS_ytdavg_gt_lyavg | EPS | +1.93% | 71.8% | 102.3 |
| C10_EPS_qmax4 | EPS | +1.69% | 69.1% | 57.1 |
| … | | | | |
| C3_ROE_qmax4 | ROE | −1.69% | 28.2% | 46.9 |
| **C4_ROE_qmax8** | ROE | **−2.33%** | 24.5% | 24.5 |

**依來源因子**：`EPS` 衍生 7 個**全部為正**（中位 +1.93%）；`ROE` 中位僅 +0.15%；
`FCF_P` 中位 −0.32%。

### ⭐ 與台股最戲劇性的對照

| C | 台股排名 | 台股增益 | 美股排名 | 美股增益 |
|---|---|---|---|---|
| **C4_ROE_qmax8** | **1** | **+6.86%** | **20（最後）** | **−2.33%** |
| C3_ROE_qmax4 | 4 | +3.84% | 19 | −1.69% |
| C12_EPS_yoy | 5 | +3.59% | **1** | **+2.68%** |

```
兩市場 20 個 C 的增益排名 Spearman = 0.149
```

**台股靠「ROE 創新高」（動能型），美股靠「EPS 年增」，而且台股的最佳條件在美股是最差的。**
這與 Phase 1 的發現一致——台股 `MOM` 是動能、美股是反轉，連帶讓最佳動態條件相反。

C 的增益幅度台股也大得多（+6.86% vs +2.68%）。可能的原因（**假說**）：
美股市場效率較高，財報動態這類公開資訊被更快定價。

## 7. C 相關：兩市場都由「來源因子」主導

```
              中位     p90     最高
美股 績效相關  0.209   0.667   0.933
美股 選股重疊  0.285   0.497   0.815
台股 績效相關  0.329   0.679   0.915
台股 選股重疊  0.306   0.510   0.844
```

拆解（績效相關中位數）：

| 配對類型 | 美股 | 台股 |
|---|---|---|
| **同因子 · 不同規則** | **0.506** | 0.406 |
| 同規則 · 不同因子 | 0.206 | 0.430 |
| 都不同 | 0.091 | 0.266 |

**美股由「用哪個來源因子」主導，差距 2.5 倍。** 這與 §4 一致——美股的 C 是依來源因子分好壞
（EPS 全正、ROE 中性、FCF_P 偏負）。

真正重複的是可以指名的兩對：`C13↔C14`（0.815）與 `C6↔C7`（0.791），
差別只在比較基準是「去年全年」還是「去年同期」。

> 🔴 先前寫的「qmax 家族跨因子塌縮 Jaccard 0.993」**是 A1 缺陷的產物**——
> 三個 qmax 都恆真，當然選到同一批。修正後最高降到 0.815。
> 連帶「美股 ROE/EPS/FCF 高度同步」的機制假說也一併作廢。

## 9. 🔴 倖存者偏誤：美股的最大限制

**美股宇宙採用 2026-07-08 的 Russell 3000 成分股快照**（`database.py::_universe_clause`），
未回溯歷史成分變動。

```
資料庫裡的美股      11,187 檔｜其中 4,765 檔（43.1%）股價停在 2026 前 ＝ 已下市/停止交易
我們的回測宇宙       2,972 檔｜其中僅 14 檔（0.5%）在 2026 前停止公告
```

**宇宙的 99.5% 是活到 2026 的公司。**

### 為什麼這對本研究特別致命

倖存者偏誤與本研究的兩個主要方向**完全重疊，而且是相乘的**：

| 策略特徵 | 下市公司的特徵 |
|---|---|
| 挑**最便宜**的估值桶 | 瀕死公司**看起來最便宜**（PB 0.2、PS 0.1） |
| 排行榜頂端集中在**最小規模桶** | 下市**集中在小型股** |

一家 2007 年 PB=0.3、2008 年下市歸零的公司，在我們的回測裡**不存在**；
但當年真的照這個策略投資的人一定會買到它。

### 三件要說清楚的

1. **美股的絕對報酬應視為上界。** 68.94% 這個數字沒有承擔任何下市風險。
2. **這是設計選擇，不是資料拿不到。** 那 4,765 檔下市公司的股價資料庫裡**已經有了**，
   被 `russell3000` 成分表濾掉。若要修，是改宇宙定義（重跑），不是重新蒐集。
3. **台股不受影響**：台股宇宙未做成分股篩選，1,775 檔中僅 36 檔（2.0%）在 2026 前停止交易。
   **→ 兩市場比較時應以台股為主要依據，美股作為方向性佐證。**
