# 策略成果報告：Phase 1~4 因子探勘與最終候選策略

> **日期**：2026-08-17
> **範圍**：台股、美股，in-sample 2000-01-01 ~ 2025-12-31（2026 保留為樣本外）
> **自建宇宙基準**（全買、含股利、同宇宙同成本）：台股 **8.67%**｜美股 **12.35%**

## 因子總表：F 有哪些、C 有哪些

在看各階段結果之前，先列出這次實驗實際用到的所有因子定義，方便對照。

### C（動態條件）—— 20 種時間動態訊號，衍生自 ROE / EPS / FCF_P

C 回答的問題不是「這家公司好不好」（那是 F 的工作），而是「**現在這個時間點，體質是不是正在變好**」——問法是「這家公司**自己**的 ROE/EPS/FCF Yield，跟**自己過去**比是不是在改善」，不是跟其他公司比。20 個 C 全部由 ROE、EPS、FCF_P 這三個因子，各自套用同一套 7 種時序規則衍生而來（FCF_P 少一種，故 3×7−1=20）。

**完整 20 個 C 清單，用完整的條件語意寫法（仿學姊論文表 4-2 的寫法；★＝學姊論文原始 8 個 C 之一，見下方對照）：**

| 編號 | 基礎因子 | 條件語意 |
|---|---|---|
| C1 | ROE | 當季 ROE 較前一季上升 ★ |
| C2 | ROE | 當季 ROE 較前兩季上升 |
| C3 | ROE | 當季 ROE 為近四季最高值 ★ |
| C4 | ROE | 當季 ROE 為近八季最高值 |
| C5 | ROE | 當季 ROE 較上年同季上升 ★ |
| C6 | ROE | 本年至今 ROE 平均高於去年**同期**平均 |

| C8 | EPS | 當季 EPS 較前一季上升 |

### 與學姊論文原始 8 個 C 的對照

學姊論文（表 4-2）的 C 構面只定義了 8 種，分屬 ROE(3)、Revenue(2)、EPS(2)、FCF(1) 四個來源因子。我們的 20 個 C **只從 ROE / EPS / FCF_P 三個來源衍生**（不含 Revenue），把她示範過的 7 種規則系統性地套滿這三個因子後擴充而成。

| 學姊 C 編號 | 基礎因子 | 條件語意 | 我們的對應 |
|---|---|---|---|
| C1 | ROE | 當季 ROE 為近**四**季最高值 | ✅ 我們的 **C3** |
| C2 | ROE | 當季 ROE 較前一季上升 | ✅ 我們的 **C1** |
| C3 | ROE | 當季 ROE 較上年同季上升 | ✅ 我們的 **C5** |
| C4 | Revenue | 當季營收為近**五**季最高值 | ❌ **無對應** |
| C5 | Revenue | 當季營收較上年同季上升 | ❌ **無對應** |
| C6 | EPS | 當季 EPS 較上年同期上升 | ✅ 我們的 **C12** |
| C7 | EPS | 本年至今 EPS 平均高於去年同期平均 | ✅ 我們的 **C13** |
| C8 | FCF（Yield） | 當季 FCF 較前**兩**季上升 | ✅ 我們的 **C16** |

**6/8 有完全對應（C1/C1、C2/C3、C3/C5、C6/C12、C7/C13、C8/C16），2/8 完全沒有對應。**

沒對上的 C4、C5 都是 **Revenue 衍生**——不是漏掉，是我們的 20 個 C 設計時就沒有把 Revenue 納入衍生來源，這兩個在我們的清單裡天生不存在。另外學姊的 C4 窗口是「近 5 季最高」，我們的 `qmax` 只有 4 季與 8 季兩種，即使把 Revenue 補回來，窗口也對不上原始定義。

其餘的 C9~C20（12 個）是我們的擴充：把學姊示範過的 7 種規則（riseq1/riseq2/qmax4/qmax8/yoy/ytdavg同期/ytdavg全年），系統性地補滿在 ROE、EPS、FCF_P 三個因子上各跑一輪——例如她只示範了 ROE 的「近4季最高」，我們把 ROE 的「近8季最高」「較前2季升」「兩種 ytdavg 版本」也都補齊，EPS、FCF_P 同理。

### V（估值濾網）

用本益比(PE)的近 4 季滾動指標當濾網：**v0**＝不套用；**v1**＝額外要求「本益比低於近 4 季均值，但高於近 4 季最低點」（相對自己歷史便宜、但非最谷底）。PE 本身不進 F 評選，只作為 V 的依據，避免同一個訊號在 F 跟 V 兩邊重複探索。

## 研究設計：一次只開一個維度

我們用 **FCV** 架構描述一個策略：

```
F（體質因子，選什麼樣的公司）× C（動態條件，時間點對不對）× V（估值濾網，貴不貴）
```

整條實驗分四個階段，**每階段只多打開一個維度**，前一階段的結論會篩選進入下一階段的候選：

```
Phase 1  單一因子健檢（9桶線性檢定，純 F，C/V 關閉）
   ↓  篩出「哪些因子夠格當主訊號 primary、哪些夠格當輔助 secondary」
Phase 2  F1×F2 配對（開 F2，C/V 仍關閉）
   ↓  篩出「哪些配對禁得起雙重檢驗」→ 晉升為候選 F 組合
Phase 3  加動態條件 C（開 C，V 仍關閉）
   ↓  在每個候選 F 組合上，測 20 種「財報有沒有變好」的時間動態訊號
Phase 4  加估值濾網 V（全開）
   ↓  測「便宜」這個濾網要不要加
```

這是老師 2026-08-05 指導的方法論：先看每個因子自己站不站得住，再看兩個因子搭配好不好，再看時間點要不要挑，最後才問貴不貴。

### 每一桶是怎麼切的

所有「分桶」都是同一套機制：**橫斷面百分位排名**——每一天，把當天所有還在市場上的公司，依因子值排名、換算成百分位（0%~100%），再依百分位切成 N 等分。

```
第 k 桶（k = 0 ~ N-1）＝ 百分位落在 ( k/N , (k+1)/N ] 的公司
```

| N=9（Phase 1 用） | 百分位範圍 |
|---|---|
| 桶0（最低） | (0%, 11.1%] |
| 桶1 | (11.1%, 22.2%] |
| … | … |
| 桶8（最高） | (88.9%, 100%] |

| N=3（Phase 2/3/4 用） | 百分位範圍 |
|---|---|
| 桶0（最低） | (0%, 33.3%] |
| 桶1（中間） | (33.3%, 66.7%] |
| 桶2（最高） | (66.7%, 100%] |

**幾個重點**：

- **每天重新排一次**，不是排一次就固定——今天的桶 0 跟明天的桶 0 不一定是同一批公司。
- **無前瞻**：排名只用「當天已經公告」的因子值，不會偷看未來。
- **沒有資料的公司（下市、還沒公告）自動不進任何桶**，不會被硬塞進某一桶。
- **桶的意義因因子而異**：像 ROE、MOM 這種「數值越大越好」的因子，桶 8（最高）通常是我們想要的那端；但像 PB、PS 這種估值倍數「數值越小越好（越便宜）」，反而是桶 0（最低）才是我們想要的那端。看圖時要留意這一點，不要看到「桶 0 表現最好」就以為是巧合。
- **N=9 跟 N=3 是各自獨立重跑的兩次回測**，不是先切 9 桶再拿數字合併成 3 桶——合併後選股清單、持股數、分散度都不同，必須實際重跑才準（這件事我們有另外驗證過，9 桶算術合併會系統性低估 3 桶實跑的報酬，中位數差距約 0.5~0.6 個百分點）。

## Phase 1：因子健檢 —— 20 個因子，誰有資格上場

### 怎麼做

把每個因子切成 9 個分位桶（0=最低分位、8=最高分位），只用該因子單獨選股（不搭配、不加時間條件、不加估值濾網），看 9 桶的 CAGR 是否**單調**跟著分位變化——用 Spearman 等級相關 ρ 衡量。

| 判準 | 意義 |
|---|---|
| \|ρ\| ≥ 0.85 | ✅ 過關 —— 幾乎完美單調，可當 primary |
| 0.5 ≤ \|ρ\| < 0.85 | ⚠️ 邊際 —— 有方向但不夠乾淨 |
| \|ρ\| < 0.5 | ❌ 淘汰 —— 沒有單調關係 |
| （特例）頭尾單獨突出 | ⚠️ 只取極端桶 —— 像動量這種「只有最強的一端有意義」的因子 |

### 結果

| 判定 | 台股（19 個可用因子） | 美股（19 個可用因子） |
|---|---|---|
| ✅ 過關 | **6 個**：P_IC、PB、PS、EV_S、MOM、ROE | **8 個**：REVENUE、P_IC、VOL、PS、EV_EBITDA、EV_S、PB、EPS |
| ⚠️ 只取極端桶 | 1 個：FCF_P | **9 個**：ACCRUAL、OCF_E、CROIC、FCF_P、ROIC、MOM、REV_G、ROE、DEBTRATIO |
| ⚠️ 邊際 | 7 個：EV_EBITDA、OCF_E、ACCRUAL、ROIC、DEBTRATIO、FCF_OI、NETDEBT_EBITDA | 1 個：NETDEBT_EBITDA |
| ❌ 淘汰 | 5 個：CROIC、VOL、EPS、REVENUE、REV_G | 1 個：FCF_OI |

**配圖**：`{市場}_phase1_curves.png`——20 個因子各畫一條 9 桶 CAGR 折線，排成小圖網格；線的顏色＝判定（綠＝過關／藍＝邊際／金黃＝只取極端桶／橘紅＝淘汰），標題附 ρ 值與全距。先看形狀、再看全距（單調性乾淨不代表訊號強）（詳細判讀方式見附錄）。

### 這階段的三個重要發現

**① 兩個市場「誰有效」幾乎是兩套名單。** 台股靠估值倍數(P_IC/PB/PS/EV_S)加動量(MOM)過關；美股除了估值倍數外，連 REVENUE、VOL、EPS 都過關，但美股大多數獲利/現金流類因子（ROE、ROIC、CROIC、ACCRUAL…）只能算「只取極端桶」——代表美股裡這些因子只有最好的那一小段有效，中間段沒有單調關係。**兩個市場的因子健檢結果不能互相套用。**

**② 價值陷阱只出現在美股，台股沒有。** 台股四個過關的估值因子（P_IC、PB、PS、EV_S）九桶零例外單調遞減，最便宜的桶 0 就是最好的一桶（`P_IC` 的 ρ 甚至是 −1.000）。但美股的 `EV_EBITDA` 與 `EPS` 最佳桶都落在**桶 1（次便宜）**而非桶 0——最便宜的那一端混進了「便宜有便宜的道理」的公司，報酬反而不如次便宜。**這個現象只有切 9 桶才看得見，切 3 桶會被完全蓋掉**，這是我們堅持先切 9 桶再判定的主要原因。

**③ 動量因子（MOM）方向在兩市場相反。** 台股 MOM 呈單調上升（ρ=+0.93，動能最強的桶報酬最高）；美股 MOM 幾乎不單調（ρ=−0.05）、呈 U 型，動能**最弱**的桶反而報酬最高。我們判斷這不是資料錯誤——持股數在各桶穩定在 180~200 檔、非少數股撐出來，且這個現象分布在 26 年裡至少 15 個年份，不是單一崩盤年撐出來的。較合理的解釋是：這裡的 `MOM` 定義（財報期末日到申報日之間 45~90 天的股價變化）落在「短期反轉」而非「中期動量」的窗口，兩者本來就是文獻上方向相反的兩種效應。

## Phase 2：F1×F2 配對 —— 兩個因子搭配，能不能「1+1 > 2」

### 怎麼做

把 19 個因子（Phase 1 判定裡除了前瞻偏誤因子外全部）切 3 桶，兩兩配對成 F1(primary)×F2(secondary)：

- **primary 的門檻**：自己單獨跑，CAGR 要贏基準 **2 個百分點**以上
- **secondary 的門檻**：自己單獨跑，不能輸基準超過 **1 個百分點**（不用贏，不拖累就好）
- **配對退步容忍**：配對後不能比兩腳裡最好的那一支單獨退步超過 0.5pp
- **持股數門檻**：平均每月至少 10 檔（老師的第二個獨立約束——「選出來的股票不能太少」）

### 我們額外驗證了「因子池要開多寬」這個設計問題

因子池的寬鬆度分四種設計來對照測試（皆用同一套門檻）：

| 設計 | primary 池 | secondary 池 |
|---|---|---|
| strict | 只有 Phase 1 過關的因子 | 邊際 + 只取極端桶 |
| relaxed | 過關 + 邊際 + 只取極端桶 | 同左 |
| all | 全部 19 個（含被淘汰的） | 同左 |
| **openSec（採用）** | 只有 Phase 1 過關的因子 | **全部 19 個開放** |

台股四種設計的完整回測顯示：

| 設計 | 晉升組合 | 最終候選 | CAGR 中位 |
|---|---|---|---|
| strict | 148 | 4,923 | 15.73% |
| **openSec** | **219** | **7,162** | 15.53% |
| relaxed | 208 | 6,887 | 15.31% |
| all | 355 | 11,488 | 15.03% |

**結論**：primary 這關嚴格篩選是有效的——放寬 primary（relaxed/all）中位數持續下滑。但 secondary 這關嚴格篩選反而會**誤殺**——openSec 把 secondary 全開放後，候選數多了 45.5%，中位數只掉 0.2pp（幾乎沒差）。原因是 Phase 1 檢定的是「這個因子自己能不能單調預測」，但 secondary 的功能不是自己預測，而是**提供不同構面的資訊**去輔助 primary，這是兩件不同的事。**故採用 openSec：primary 嚴格把關，secondary 全部開放。**

**美股四種設計的完整回測（2026-08-18 補齊）**：

| 設計 | 晉升組合 | 最終候選 | CAGR 中位 |
|---|---|---|---|
| strict | 176 | 6,486 | **23.68%** |
| **openSec** | **188** | **6,916** | 23.61% |
| relaxed | 281 | 10,137 | 21.52% |
| all | 316 | 11,386 | 21.22% |

**同一個結論在美股再次成立，但效果量小很多**：primary 放寬一樣讓中位數明顯下滑（strict→relaxed 掉 2.16pp，跟台股 strict→all 掉 0.70pp 方向一致但幅度更大）；secondary 全開放（openSec vs strict）候選數 **+6.6%**、中位數只掉 0.07pp——同樣幾乎無感。差別在於**美股 secondary 開放帶來的候選增幅遠不如台股的 +45.5%**，代表美股「被淘汰因子當 secondary 也有用」這個現象沒有台股明顯，但方向完全一致。**兩個市場獨立驗證，openSec 設計都站得住。**

### 這階段的發現：加 secondary 平均是小虧，但少數配對是意外驚喜

統計全部配對「加了 secondary 之後」比「primary 自己單獨跑」多贏或少輸多少：**中位數 −0.65%**，僅 30.9% 的配對是正的，代表大多數配對是小幅侵蝕報酬。但分布有一條**長尾巴**，一路拖到 +7.4%——少數配對反而大幅加分。

拆到「因子＋桶」層級看才知道哪些搭配安全，不能只看因子名——例如 `EV_EBITDA` 同時是最不拖累**與**拖累最重的來源，端看取哪一桶：

| 最不拖累（桶） | 中位增益 | | 拖累最重（桶） | 中位增益 |
|---|---|---|---|---|
| `EV_EBITDA_qb0`（最便宜） | **+2.01%** | | `EV_EBITDA_qb2`（最貴） | **−5.11%** |
| `REVENUE_qb0`（最小型） | +1.47% | | `MOM_qb0`（動能最弱） | −4.69% |
| `ROE_qb2`（獲利最強） | +1.40% | | `PB_qb2`（最貴） | −4.43% |

## Phase 3：加動態條件 C —— 財報有沒有變好，這個時間點值不值得進場

### 怎麼做

20 種「財報有沒有變好」的時間動態訊號，全部衍生自 ROE / EPS / FCF_P 三個因子（例如「比上一季高」「創近 4 季新高」「比去年同期高」…），加到 Phase 2 晉升的每個候選 F 組合上。**C 的價值＝同一個 F 組合「加了這個 C」比「完全不加任何 C」多贏多少**——這樣才是控制 F 之後看 C 的乾淨效果，不是把所有 F 混在一起平均。

### 結果：控制 F 之後，C 的效果在兩個市場截然不同

**台股**：20 個 C 裡有 14 個中位數是正的，整體明顯加分。

|---|---|---|---|
| 1 | **C4（ROE 創近 8 季新高）** | ROE | **+6.86%** |
| 2 | C11（EPS 創近 8 季新高） | EPS | +5.02% |
| 3 | C5（ROE 較去年同季升） | ROE | +3.85% |

ROE 衍生的 C 整體中位 +2.96%、EPS 衍生 +2.71%，都明顯偏正；只有 FCF_P 衍生的 C 是負的（−0.99%）。

**美股**：20 個 C 大多貼著 0，只有前幾名明顯偏正。

## Phase 4：加估值濾網 V —— 便宜這件事，加了到底划不划算

### 怎麼做

對 Phase 3 產出的候選策略，比較「不加估值濾網」(v0) 跟「加估值濾網：本益比低於近 4 季均值但高於近期低點」(v1) 的差異，同時看報酬（ΔCAGR）跟風險（ΔMDD）兩個維度，畫成四象限：

| 象限 | 意義 |
|---|---|
| ① 報酬升、風險降 | 雙贏 |
| ② 報酬升、風險升 | 換風險買報酬 |
| ③ 報酬降、風險降 | 換報酬買穩定 |
| ④ 報酬降、風險升 | 雙輸 |

|---|---|---|
| ΔCAGR 中位數 | **−1.96%** | **−5.74%** |
| ΔCAGR 為正比例 | 27.9% | 9.8% |
| ① 雙贏比例 | 13.8% | 3.9% |
| ④ 雙輸比例 | 48.1% | 72.8% |

## 結論

**1. 兩個市場的因子健檢結果、C 動態訊號排名都不能互通。** 台股靠估值 + ROE 動能延續，美股靠估值 + EPS 盈餘年增，兩者的最佳 C 訊號幾乎互斥。任何要跨市場套用的規則都必須重新獨立驗證。

**2. F1×F2 配對驗證了「主訊號要嚴、輔助訊號要鬆」的設計是對的**——openSec 設計（primary 嚴格用 Phase 1 過關因子、secondary 全開放）比全嚴格(strict)或全放寬(all)都更好：嚴格篩 primary 能持續守住品質，但嚴格篩 secondary 反而會誤殺掉一批表現不錯的配對。

**3. 動態條件 C 在控制 F 之後才看得出真正效果**——不控制 F 直接比較 20 個 C，看起來彼此差不多；控制 F 之後，台股 14/20 個 C 明顯加分（最高 +6.86%），美股則是少數幾個 EPS 衍生的 C 明顯加分，其餘大多貼著 0。

**4. 估值濾網不是無條件划算的**——兩個市場加了估值濾網後，多數策略報酬和風險同步惡化（雙輸），尤其美股 72.8% 的策略如此。是否加估值濾網要看策略的體質背景，不建議預設套用。

**5. 最終候選池**：台股 7,162 個、美股 6,916 個候選策略通過完整 Phase 1~4 篩選，且都贏過各自的自建宇宙基準（台股 8.67%、美股 12.35%）。Top 策略在兩市場都呈現「估值因子 + 獲利能力動態訊號」的組合型態，但要留意持股數分散度與規模因子的依賴程度再做最終取捨。

**怎麼讀**：先看整條線的**形狀**——是不是一路往上（或一路往下）；再看有幾個點站在虛線之上（贏基準）；再看標題的**全距**（同樣是 ρ=0.85 以上的過關因子，全距可能差到 6 倍以上，例如台股 `ROE` 全距只有 2.7pp、`PB` 卻有 18.0pp——單調性乾淨不代表訊號強）；最後才看 ρ 數字做確認。**特別注意**：像 PB/PS/P_IC/EV_S 這類估值因子，線是**向下**的（桶 0 最高、桶 8 最低）才是健康的，因為桶 0＝最便宜；不要因為線往下就誤判成「因子沒用」。**MOM1** 的 Y 軸量級明顯比其他因子大一截（全距近 90pp）——那正是前瞻偏誤的視覺特徵，圖上保留是為了呈現「偏誤長什麼樣子」，不列入評選。

### Phase 2：`{市場}_L2_openSec_pairing_gain.png`

這張圖分兩格，回答「加副因子(secondary)到底有沒有幫助」。

**左格（直方圖）**：
- X 軸＝「配對後 CAGR」減「主因子(primary)單獨跑 CAGR」的差距，橘色虛線是 0
- 落在 0 右邊＝加了副因子後**變好**；左邊＝**變差**
- 看整體長條堆在哪一側、中位數標在圖例上

**右格（盒鬚圖，依中位數排序）**：
- 把左格混在一起的全部配對，拆成「跟哪個副因子搭配」分別畫一個盒子——**注意這是依「因子」分組，同一因子的不同桶會被畫進同一個盒子**，看不出桶內差異（桶內差異要另外拆表，見 Phase 2 內文「拆到因子＋桶層級」那段）
- 黑線＝中位數、綠色三角＝平均、盒子＝中間 50% 配對落點、圓圈＝離群個案
- 最左邊＝搭配後平均表現最好的副因子，最右邊＝拖累最多的

**怎麼讀**：這張圖天生會偏負（因為 secondary 的任務本來就不是「贏過 primary」，只要不拖累太多即可），**重點不是看中位數是不是正的，而是看①長尾巴有多長（左格有多少配對衝到很高的正值）②哪個因子相對安全**，但若要精確判斷「哪一桶」安全，要另外查表，不能只看這張圖。

### Phase 3：`{市場}_L3_openSec_C_gain.png`

跟 Phase 2 的配對圖結構很像，但這裡比的是「同一個 F 組合，加 C 前後差多少」（而不是「主因子單獨 vs 配對」）。

**左格（盒鬚圖，20 個 C 依中位數排序）**：
- Y 軸＝「加了這個 C」比「同一個 F 組合完全不加任何 C」多贏或少輸多少
- 橘色虛線＝0（不加不減的分界線）
- **盒子顏色＝這個 C 是從哪個因子衍生的**（藍＝ROE、綠＝EPS、橘＝FCF_P）

**右格（直方圖，依來源因子分三群疊圖）**：
- 把 20 個 C 依來源因子（ROE／EPS／FCF_P）分三群，各自的增益分布疊在一起看
- 圖例會標三群各自的中位數，一眼比較「哪個來源的 C 整體比較有用」——**這個圖例數字是逐策略直接取中位數，不是先算 7 個 C 各自的中位數再取中位數；兩種算法在美股台股都可能算出不同排序，本報告與圖表一律採用前者**

**怎麼讀**：**先看右格**判斷這個市場整體是哪個來源因子的 C 比較有效，**再看左格**找出該來源裡最強的具體那一個 C（例如台股先看到「ROE 衍生整體最強」，再從左格找出是 C4 最強）。**兩個市場的圖務必放在一起比**——這正是這階段最重要的發現。

### Phase 4：`{市場}_L4_openSec_V_effect.png`

這張圖有三格，從粗到細層層拆解「加估值濾網 V1 值不值得」。

**左格（4-20，直方圖）**：ΔCAGR(v1−v0) 的分布，虛線＝0。堆在 0 左邊代表加了 V1 之後大多數策略報酬變差。

**中格（4-21，四象限散布圖，這張最關鍵）**：
- X 軸＝ΔMDD（往右＝v1 回撤變淺、風險降低）
- Y 軸＝ΔCAGR（往上＝v1 報酬升高）
- 四個顏色＝四個象限，圖例會標各象限佔比：
  - 🟢 右上＝①雙贏（報酬升、風險也降）
  - 🔵 左上＝②報酬升但風險也升
  - 🟡 右下＝③換取穩定（報酬降、但風險也降）
  - 🟠 左下＝④雙輸（報酬降、風險還升）
- **理想是看綠色點的佔比跟位置**；若橘色點(雙輸)佔多數且分布很開，代表這個濾網對這個策略池整體不划算

**右格（4-23，盒鬚圖，依 C 分組）**：把 ΔCAGR 拆成「原本配哪個 C」分別看，找出「跟哪個 C 搭配時加 V1 比較不傷」。

**怎麼讀**：先看中格的顏色佔比抓整體結論，再看右格找出例外（如果要在某些特定 C 上加 V1，右格能告訴你該挑哪些）。
