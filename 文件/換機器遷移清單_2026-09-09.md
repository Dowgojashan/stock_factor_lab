## 三、建議順序

1. **先 commit** `_frozen/` 進 git 的這次變更（已 `git add`，等你執行 `git commit`）
2. 資料庫服務**先關閉**，備份 `C:\xampp\mysql\data\`
3. 複製 `config.ini`
4. 決定 490GB 封存區要不要搬、搬哪幾個（見上方影響評估），機密文件視需要複製
5. 確認 git 這個 repo 有 push 到遠端，或整個資料夾也複製一份保險
6. 新機器：`git clone`（`_frozen/` 這次會跟著回來）→ 放回 `config.ini`／
   決定要帶的封存區 → 跑 `setup.bat` 建 `.venv` → 還原資料庫 →
   跑 `python -m research.tests` 確認 131 項還過
